## 役割

- **オーナー**: 投稿ボタンを押す・各サービスへのログイン・フォームの名前とメール入力・コメントへの返事

## 投稿前の共通チェック

- 個人名・個人メールアドレスを本文に書かない（運営者名は「motytools」）
- 各下書きの「投稿前に確認すること（オーナー）」の項目を読む（とくに Show HN の「AIで下書きした」「広告あり」の書き方が事実どおりか）
- Zenn・Qiita の冒頭にある `<!-- 投稿メモ -->` は消してから投稿する
- 図鑑のページを1度開き、リンク先が表示されることを確かめる

## 見込み（数字は保証できないので幅で）

- **Zenn / Qiita**: 中身で評価される場所。トレンドに乗れば数日で数千回読まれ、図鑑へも一定数流れる。乗らなければ数百回。検索からも長く読まれる
- **Show HN**: 当たり外れが大きい。一面に乗れば1日で数千〜1万人規模、乗らなければほぼ0。1回勝負
- **Reddit**: 数十〜数百人。指摘コメントが図鑑の質を上げる材料になる価値が大きい
- **GitHub のまとめリスト・ニュースレター**: 1件あたりの人数は少ないが、載れば何年も残る。検索での評価（被リンク）にも効く。取り込みまで数週間〜数か月
- 図鑑は広告（AdSense）収益が入るページなので、どの経路でも読まれた分だけ収益と検索評価が伸びる
