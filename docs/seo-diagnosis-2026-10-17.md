# motytools.com 検索登録の診断（2026-10-17）

調べ方: Search Console の読み取り専用API（検索実績90日 2026-07-15〜10-14、URL検査41件、サイトマップ状況）、本番ページの取得（約2,200ページの本文量を計測）、各リポジトリの引き継ぎメモと git 履歴。サイトのファイル変更・公開・Googleへの送信は一切していない。

## 0. 結論（先に）

1. **一番の原因は「Googleからまだ信用されていない新しいドメイン」と「外からのリンクがゼロ」。** 技術的な故障ではない。ドメイン取得は 2026-06-04（4か月半）。motytools.com の各ページを指しているリンクを Google は1本も把握していない（検査した motytools.com の22件中21件で「参照元0件」。唯一の例外のトップは、参照元3件が全部 roster.motytools.com のチャンネルページ）。
2. 症状は2種類に分かれる。
   - **読んだが載せない**（クロール済み・未登録）: /tools/・/tedori/・/apps/・/guide/・/ugoki/・/ui/・/en/motion/ など。10/14〜10/17に読まれている。本文は2,000〜8,000字ある。→ 中身の問題ではなく「サイト全体の評価がまだ低い」。
   - **存在すら知らない**（URLが認識されていない）: /guide/ の記事5本すべて、/wareki/、/ui/modal/、/buzzmeter/、/anzen/ の市区町村ページ全部。→ サイトマップは10/15に読まれた（331件・エラー0）のに、Googleが「わざわざ見に行く価値がある」と判断していない。
3. **案A（自分の登録済みサイトからリンク）が最も効く。** ただし「全ページのフッターに motytools の文字リンク」はやらない。中身が噛み合うページ同士だけ、文章の中で張る。持ち主のサイトで実際に検索に出ているのは 住まいの価格ナビ（表示11.9万回）・クルマ相場ナビ（3.8万）・年収相場ナビ（2.4万）・発見ラボ（4,188）・高級車情報（3,187）・湘南台ガイド（2,599）。**今この6サイトから motytools.com へのリンクは0本**（トップページで確認）。
4. **案B（薄いページを外す）は、motytools.com本体への効き目は小さい。** Googleが本体のページを「読んでも載せない」のは、読む回数が足りないからではない（読んだ上で断っている）。ただし片付けとしては価値がある: 炎上マップの人物ページ717件のうち **694件（97%）は案件が1件だけ**で、案件ページとほぼ同じ内容の二重ページ。安全マップの地図ページ5本は、Googleから見える文字が110〜145字しかない。
5. **AとBより先に・並行してやると効くもの**: ①外部のちゃんとした場所に1〜3本リンクを置く（開発者向けの記事サイトで「動きの図鑑」を紹介する等。持ち主のアカウントが要る）②motytools.com の中のリンクを強める（トップ→記事・ツール→記事・記事→ツール）③登録リクエストを強いページから1日10本ずつ。

## 1. なぜ motytools.com はほとんど載らないのか（証拠の強い順）

### 原因1: 新しいドメインで、外からのリンクがない（影響: 大・証拠: 強）

- URL検査で「参照元」（Googleが知っているリンク元）を見ると、motytools.com の22件中 21件が0件。トップだけ3件あり、それが全部 roster.motytools.com の個別チャンネルページ。つまり Google は自分の兄弟サブドメイン経由でしか motytools.com を見つけていない。
- 持ち主の他サイト9つ（住まいの価格ナビ、www版、年収相場ナビ、クルマ相場ナビ、高級車情報、診断ラボ、発見ラボ、Who Looks Like、湘南台ガイド）のトップに motytools へのリンクは0本。

### 原因4: 安全マップの地図ページは、Googleから見ると中身がほぼ空（影響: 小〜中・証拠: 強）

### 原因5: 技術的な問題 — 見つからず（影響: なし）

### 9月の「知っているページ 約1.2万→約3千」の落ち込みは何か

- 炎上マップ: 9/5 時点 770件 → 今 1,575件（こちらは増えている）。
- 一度も読まれていない「見つけたが未登録」のURLは、サイトマップから外れてリンクも弱いと、Googleの一覧から消えていく。数の減り方（Roster＋安全マップで約9千減）とも合う。

### 張り方（おすすめ）
- **文章の中で、そのページを読んだ人が次に知りたいものへ**だけ張る。全ページ共通のフッターに「motytools」と並べるやり方はしない（Googleの「同じ持ち主のサイト同士の過剰な相互リンク」に当たりやすく、効き目も小さい）。運営者ページ（about）に「運営: motytools」と1本置くのは自然でよい。
- 文言は行き先の中身そのもの。例:「港区の交通事故の件数（2024年）を見る」「賞与・扶養を入れて自分の手取りを計算する」。「無料ツール」「motytools」だけの文言は避ける。
- 本数の目安と行き先:
  1. **住まいの価格ナビ → 安全マップの市区町村ページ**: 安全マップ側が「検索に出す」と決めている市区町村（交通事故162・不審者111）に限って、同じ市区町村の価格ページから1本ずつ。最大で約270本、市区町村が重なる分だけ。安全マップの引き継ぎによると副導線を10/25反映予定。これを最優先で前倒しする価値がある。重い公開（数十分〜1時間）なので、他の修正と1回にまとめる。
  2. **年収相場ナビ → motytools.com/tedori/**: 手取りページ（/tedori/<年収>/）から「賞与・扶養を変えて計算する」を1本。ページ数は数十〜百程度。
  3. **発見ラボ → 記事1〜2本**（例「無料で使える計算ツールを作った話」「Webの動きの図鑑を作った」）。中身のある記事にして文中で紹介。
  4. 湘南台ガイド → 藤沢市の安全マップ1本（公開経路が未確認なので後回し）。
- 期待できる効果: Googleが motytools.com のURLを「見つける」（認識されていない→読まれる）には確実に効く。順位や「読んだが載せない」の解消への効き目は中くらい（自分のサイト同士のリンクは評価が割り引かれる）。

### 危険と、自然に保つ決まり
- 危険: 相互リンクの大量設置、文言を検索語で揃える、関係のないページからのリンク。
- 守ること: ①読者に役立つ場所だけ ②文言は中身の説明 ③1ページから motytools へは1本 ④逆方向（motytools→各サイト）も、関係のあるページから自然な分だけ ⑤広告の導線と混ぜない。

| Roster チャンネルページ | 約2.2万 | 既に登録者10万人未満は noindex | 対応済み |

### noindex はサブドメイン越しに効くのか（正確に）
- **Googleは「どれだけ読みに来るか」をホスト名ごとに決める**（公式のクロールの説明）。firemap.motytools.com や roster.motytools.com のページ数が、motytools.com を読む回数を食うことはほぼない。
- 品質の評価も、Googleは「サブドメインは基本的に別のサイトとして扱うことが多いが、場合による」と説明している。今回の実データも別扱いを示している: Roster のチャンネルページは表示が出ている（13ページで31回）のに、motytools.com 本体は載っていない。足を引っ張り合っている証拠も、助け合っている証拠もない。
- よって **firemap.・roster. を noindex にしても motytools.com 本体はほぼ変わらない**と見る。本体に効く可能性があるのは同じホストにある **/anzen/** だけ。
- しかも本体のページは「読む回数が足りない」のではなく「読んだうえで断られている」ので、読む枠を空ける効果は今は小さい。

### それでもやる価値がある片付け
1. **炎上マップ: 案件1件の人物ページ694件を、サイトマップから外して noindex,follow**（ページとリンクは残す）。2件以上の23件だけ人物ページとして出す。二重ページを減らすのは炎上マップ自身のため。
2. **炎上マップの旧住所の引っ越し**: firemap.alazora.workers.dev のページは Google に「登録済み」（Googleが選んだ正規URLは workers.dev 側。最終クロール 9/30・10/1）。10/7 に新住所への301転送を入れたので、Googleが旧住所を読み直すと順に移る。何もしなくてよいが、Search Console の「アドレス変更」は同じ種類のプロパティ同士でしか使えないため使えない。新住所のサイトマップは10/7に1回読まれただけ。
3. **安全マップ: 市区町村ページ（約530件）を4週間だけサイトマップから外す**（noindex にはしない・リンクは残す）。本体ホストのサイトマップの3分の2が同じ型の数字ページなので、Googleが最初に読む見本を記事・ツール・図鑑に寄せる狙い。戻すのは本体のページが10件以上登録されてから。地図ページ5本には、地図の下に文章（何が分かるか・出典・県別の主な数字）を200〜400字足す。
4. **炎上マップを motytools.com から切り離すかは持ち主の判断**。実在人物の炎上まとめは、ツール・アプリのブランドと同居すると評判面で不利になりうる（検索の仕組みより、アプリ審査や広告審査の目で見たとき）。独自ドメインへの移転は年1,500円前後。
