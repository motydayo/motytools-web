個人教室の生徒管理表は、塾向けの管理システムのような細かい項目を持たず、**10列ほどの台帳**から始めるのが続けるコツです。この記事では、エクセル（Googleスプレッドシートも同じ）で作る台帳の項目、月謝の表と結びつける方法、指導メモの残し方、個人情報の扱いを説明します。

## 生徒管理表に入れる項目

検索すると、塾やスクール向けの項目が多数出てきますが、個人教室では持ちすぎると更新が続きません。最小の形は次のとおりです。

| 見出し | 入れるもの | 理由 |
|---|---|---|
| 生徒ID | S001、S002 など | 同姓同名や名前の変更があっても、他の表と結べる |
| 氏名 | | |
| ふりがな | | 並べ替えに使う |
| 生年月日 | 年齢は数式で出す | 学年は毎年変わるので、年齢を数式で出す |
| 保護者名 | | 兄弟の確認、請求先 |
| 連絡先 | 電話、LINEなど | 欠席連絡の窓口 |
| コース・曜日・時間 | 月曜16時（30分）など | 時間割づくり |
| 月謝額 | | 月謝表に引き継ぐ |
| 入会日 | | 月途中の入会の計算に使う |
| 状態 | 在籍・休会・退会 | 絞り込みと集計 |
| メモ | 連絡の希望など | 短く |

**個人教室ではまず不要な項目**は、学校名、担任、成績、志望校、模試の結果などです。必要になった時点で足せば足ります。健康や体調に関わることは、レッスンで必要な範囲だけにとどめ、書く前に本人や保護者に確認を取ってください。

## 作り方の手順

1. 1行目に上の見出しを入れ、2行目から生徒を1人1行で入れる
2. **生徒IDは、退会した生徒の番号を再利用しない**。S001が退会しても、次はS005にする
3. 「状態」の列に、プルダウンを作る。範囲を選び、エクセルは「データ」の「データの入力規則」、スプレッドシートは「データ」の「データの入力規則」で、リストに「在籍,休会,退会」を入れる
4. 1行目を固定する。エクセルは「表示」の「ウィンドウ枠の固定」、スプレッドシートは「表示」の「固定」を使う
5. 「フィルター」を付け、曜日や状態で絞り込めるようにする

よく使う数式を3つ載せます。生徒3人のサンプルで、結果を確かめています。

- 在籍中の人数（状態が列Cの場合）: `=COUNTIF(C2:C51,"在籍")`
- 月曜日の在籍者（コースが列B、状態が列C）: `=COUNTIFS(B2:B51,"月*",C2:C51,"在籍")`
- 年齢（生年月日が列D）: `=DATEDIF(D2,TODAY(),"Y")`

例として、2015年5月3日生まれの生徒は、2026年10月12日の時点で11歳と出ます。

### 月謝表とのひも付け（生徒ID）

月謝の入金表では、生徒の名前や月謝額を台帳から引いてきます。入金表の側に氏名を手で打つと、名前の変更や入力ミスで、台帳と食い違います。入金表にはIDだけを入力し、`INDEX`と`MATCH`で台帳から引く形にします。数式と手順は[月謝管理表のエクセルテンプレート](/guide/gessha-kanrihyo-excel/)に載せています。

## 指導メモ・カルテの残し方

台帳の「メモ」欄に毎回の指導を書き足すと、すぐに行が埋まります。**指導メモは別のシート**に分けます。

| 列 | 内容 |
|---|---|
| A | 日付 |
| B | 生徒ID |
| C | 扱った曲・内容 |
| D | できたこと |
| E | 課題 |
| F | 次回やること |

生徒IDで絞り込めば、1人ぶんの経過が時系列で見えます。書く項目と続け方は[講師のレッスン記録の書き方](/guide/lesson-kiroku-karte/)で詳しく説明しています。

## 入会と退会のときに台帳でやること

台帳は、入会と退会の場面で、更新漏れが起きやすくなります。手順にしておくと、抜けが減ります。

### 入会のとき

1. 氏名、保護者名、連絡先、希望の曜日と時間を聞く
2. 規約（月謝、支払期日、振替、休会・退会）を渡し、「読みました」の返事をもらう
3. 個人情報の利用目的を伝える
4. 台帳に1行足し、IDを振る。入会月は、入会した月の1日で入れる
5. 月謝の入金表に、IDを追加する

規約の中の振替の決め方は[振替レッスンのルールの決め方](/guide/furikae-lesson-rule/)を参考にしてください。

### 退会のとき

1. 退会の申し出の日付と、最後のレッスンの日をメモに残す
2. 最後の月の月謝を精算する
3. **行は消さずに、状態を「退会」に変える**。IDの重複を避け、過去の入金を確認できるようにするためです
4. 保管期間が過ぎたら、連絡先などの個人情報を消す

### 曜日別の時間割を見る

台帳の「コース・曜日・時間」の列にフィルターを付け、曜日で絞ると、その日に来る生徒が出ます。見やすい時間割にしたい場合は、別のシートに、行を時間（15:00、16:00…）、列を曜日にした表を作り、セルに生徒の名前を入れます。台帳とは別に更新が要るので、生徒が10人前後までの方法です。

## 個人情報の扱いで気をつけること

生徒と保護者の名前・連絡先は、個人情報です。**「うちは小さい教室だから関係ない」ということはありません。** 個人情報保護委員会のQ&Aでは、個人情報データベース等を事業に使っている者は、扱う人数の多い少ないにかかわらず個人情報取扱事業者に当たるとされています（[個人情報保護委員会のQ&A](https://www.ppc.go.jp/personalinfo/faq/APPI_QA/)、2026年10月12日確認）。

同じQ&Aは、利用目的を「できる限り」特定するよう求めており、「サービスの向上のため」のような抽象的な書き方だけでは足りないとしています。教室なら、たとえば次のように伝えます（例）。

> 生徒様・保護者様の情報は、レッスンの運営、日程や連絡のご案内、月謝のご請求と入金の確認のために使用し、それ以外の目的では使用しません。

守りたい運用は次のとおりです。

- ファイルにパスワードを付ける（保存時の暗号化も含む）
- 共有するクラウドの範囲を、自分だけ（または必要な人）に限る
- 持ち歩く端末には画面ロックをかけ、紛失したときの対応を決めておく
- 退会した生徒の情報を、いつまで持つかを決め、期間が過ぎたら消す
- 本人の同意なく、他の人や会社に渡さない

法律の細かい適用は、個人情報保護委員会の案内や、弁護士などの専門家に確認してください。

## 表からアプリに移るタイミング

エクセルの台帳で困り始めるのは、次のようなときです。

- 生徒が10人を超え、曜日別の確認や振替の管理が増えた
- 外出先やレッスン室で、スマホから見たり直したりしたい
- 月が変わるたびに、列の追加や数式の修正が必要になった

ここからは自社アプリの紹介です。motytools（このサイトの運営者）が作っているiPhoneアプリ「[レッスン手帳](/apps/lesson-techo/)」は、生徒・曜日・月謝・出欠・振替をまとめて管理します。生徒の登録では、名前（必須）、ふりがな、月謝方式（月謝制か都度払い）、月謝額、支払期日、振替権の有効日数、在籍状況（在籍・休会・退会）、連絡先メモ、メモ、そして定期レッスン（曜日・開始時刻・時間・毎週か隔週か）を入力します。

**エクセルの台帳との違い**も書いておきます。生年月日や住所の専用の項目はなく、連絡先は「連絡先メモ」に自由に書く形です。表の読み込み機能もないので、生徒は手で登録します。データは端末の中だけに保存され、会員登録は不要です。無料は生徒5人までで、6人以上はPremium（月額480円、年額4,600円）が必要です。

アプリを選ぶときの全体の考え方は、[月謝管理アプリの比較](/guide/gessha-kanri-app/)にまとめています。
