不動産所得の経費で迷う大半は、「これは経費になるのか」ではなく、「どの項目で、いくら記録するのか」です。この記事では、国税庁の案内で確認できた項目を、勘定科目（帳簿で支出を分ける項目名）つきの一覧にし、経費にならないもの、迷いやすいもの、記録の残し方を説明します。何が経費になるかの最終判断は、税務署か税理士に確認してください。

## 必要経費の考え方

不動産所得は、収入金額から必要経費を引いて計算します。国税庁のタックスアンサー（[No.1370](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1370.htm)）は、必要経費の例として、固定資産税、損害保険料、減価償却費、修繕費を挙げています。基本の考え方は、不動産の貸付けに関係する支出で、家事上の支出と区分できるものを経費にする、というものです。

物件ごとに分けて記録する理由は3つあります。物件ごとの利益が見える、減価償却や借入の利子が物件に結びつく、事業的規模にあたるかの判断（アパートでおおむね10室以上、独立家屋でおおむね5棟以上が目安、[No.1373](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1373.htm)）に使える、の3つです。

## 経費になるもの一覧

国税庁の冊子「帳簿の記帳のしかた（不動産所得者用）」（[PDF](https://www.nta.go.jp/taxes/shiraberu/shinkoku/kojin_jigyo/kichou07.pdf)、令和8年5月1日現在の法令等、2026年10月12日に確認）の「一般的な必要経費の一覧表」をもとに、整理しました。

| 項目 | 勘定科目 | 内容と記録のポイント |
|---|---|---|
| 固定資産税・都市計画税 | 租税公課 | 賃貸している土地や建物の税。納税通知書を保管 |
| 不動産取得税、登録免許税、印紙税 | 租税公課 | 賃貸の建物などについての税。取得時の費用の扱いは税理士に確認 |
| 火災保険料 | 損害保険料 | 賃貸している建物などについての保険料 |
| 修繕のための費用 | 修繕費 | 後述の資本的支出との区別に注意 |
| 建物などの償却費 | 減価償却費 | 取得価額を耐用年数に分けて計上 |
| 借入金の利子 | 借入金利子 | 賃貸の建物などの取得のための借入金の利子 |
| 管理会社への手数料 | 管理手数料など | 冊子の記載例に、項目名を付けて記録する形が示されています |
| 敷地の地代 | 地代家賃 | 土地を借りている場合 |
| 管理や集金のために雇った人の給料 | 給料賃金 | 生計を一にする配偶者や親族は除く |
| 帳簿・文房具、取得価額10万円未満の備品 | 消耗品費 | 使用可能期間が1年未満のものも含む |
| 回収できなくなった家賃 | 貸倒金 | すでに収入にした未収家賃。事業として行う貸付けの場合 |
| 建物の取壊しや災害による損失 | 固定資産等の損失 | 事業として行う貸付けの場合 |
| ほかの項目に当てはまらない事業上の費用 | 雑費 | 項目を自分で付けて記録してもよい |

見落としやすいのは、契約書にかかる印紙税、帳簿や文房具の購入費、10万円未満の備品、取壊しや災害の損失です。ただし、貸倒金と取壊し・災害の損失は、不動産の貸付けが事業として行われているかどうかで扱いが変わります。国税庁はNo.1373で、事業か否かで資産損失や貸倒損失の扱いが異なるとしています。当てはまるか分からない場合は、税務署に聞いてください。

## 経費にならないもの・注意が要るもの

### 借入金の元本

賃貸の建物を取得するための借入金は、利子が必要経費になります。一方、返済額のうち元本にあたる部分は、必要経費になりません（冊子の一覧による）。毎月の返済額をそのまま経費として記録すると、経費が多くなりすぎるので、返済予定表で利子の額を確認して記録します。

元本は経費になりませんが、手元のお金は出ていきます。この差が、帳簿の利益と手元に残るお金がずれる理由の1つです。

### 家事と共用の支出

自宅の一部を賃貸にしている場合など、賃貸に使う部分と家事に使う部分が混ざる費用は、分けて記録します。冊子には、固定資産税の住宅分のうち家事分を50パーセントとして差し引く記載例があります。分け方の基準は個別の事情で変わるので、決め方は税理士や税務署に確認してください。

そのほか、冊子の一覧では、所得税や住民税、相続税、国民健康保険税、罰金や交通反則金などは、必要経費にならない税金として示されています。個人的な支出も、賃貸との関係を説明できなければ経費に入れません。

## 減価償却費の考え方

建物は、買った年に全額を経費にせず、耐用年数に分けて少しずつ経費にします。国税庁は、減価償却を、減価償却資産の取得に要した金額を一定の方法で各年分の必要経費に配分していく手続だと説明しています（[No.2100](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2100.htm)）。土地は、時の経過で価値が減らない資産なので、減価償却の対象になりません。計算の手順は[不動産の減価償却の計算方法](/guide/genka-shokyaku-fudousan/)にあります。

修繕のための支出が、修繕費になるか、資本的支出になるかも判断が分かれる点です。[No.1379](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1379.htm)では、名目ではなく実質で判定するとされています。資産の価値を高めたり使える期間を延ばしたりする部分は資本的支出で、減価償却を通じて経費になります。修理や改良がおおむね3年以内の周期で行われるものや、1回の金額が20万円未満のものは、修繕費として申告すると、その年の必要経費にできます。区分が明らかでない金額が、60万円未満、または前年末の取得価額のおおむね10パーセント以下なら、修繕費として扱えます。

取得価額が10万円以上20万円未満の償却資産には、3年間で均等に必要経費にする特例もあります（冊子の一覧による）。

## 領収書と記録の残し方

支出は、支払ったときに、日付、支払先、金額、項目、物件を記録します。保存期間は、国税庁の案内で、帳簿が7年、請求書や領収書などの書類が5年とされています。青色申告では、現金預金取引等関係書類は7年（前々年の所得が300万円以下の場合は5年）です（[No.2080](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2080.htm)、冊子）。

領収書を撮影して残しておくと、紙をなくしたときにも内容が分かります。ただし、スマホで撮った画像を原本の代わりにするには、電子帳簿保存法の要件を満たす必要があります。要件を確認するまでは、原本も取っておくのが安全です。
