リフォームや引っ越し、不動産の売買や賃貸など、大きなお金が動く契約の前には、その業者が行政処分を受けたことがないかを調べられます。調べ先は、国土交通省、消費者庁、都道府県と、省庁ごとに分かれています。この記事では、リフォーム業者や不動産会社などの処分歴を無料で確かめる手順と、調べた結果の読み方を説明します。

## 行政処分とは

行政処分は、事業者が法律に違反したときに、国や都道府県が法律に基づいて出す処分です。免許や許可の取り消し、一定期間の営業や業務の停止、改善を求める指示などがあります。どの処分があるかは、業種ごとの法律で決まっています。

行政処分は、口コミや苦情とは違います。違反が行政に確認され、手続きを経て決まったものだけが、公表の対象になります。

## 国交省のネガティブ情報等検索サイト

国土交通省の[ネガティブ情報等検索サイト](https://www.mlit.go.jp/nega-inf/)では、国土交通省が所管する事業者の過去の行政処分歴を検索できます（2026年10月12日に操作して確認）。暮らしに関わる主な事業分野は次のとおりです。

| 頼む内容 | 事業分野 |
|---|---|
| リフォーム・工事 | 建設業者 |
| 住宅の設計 | 一級建築士 |
| 不動産の売買・賃貸の仲介 | 宅地建物取引業者 |
| 賃貸住宅の管理 | 賃貸住宅管理業者等 |
| マンションの管理 | マンション管理業者 |
| 民泊施設の管理 | 住宅宿泊管理業者 |
| 引っ越し・宅配 | トラック事業者（別ページへ移ります） |
| 旅行 | 第一種旅行業者（観光庁のページへ移ります） |

### 検索の手順

1. サイトのトップで「事業分野を選択」から分野を選び、「事業者を選択」で、調べたい事業者（例: 宅地建物取引業者）を選びます
2. 検索の画面で、絞り込みの条件を入れます。宅地建物取引業者の場合、「処分等年月日」（年と月を組にして指定します）、「処分等を行った者」（都道府県や地方整備局など）、「事業者名」、「都道府県」、「処分等の種類」（免許取消、業務停止、指示、行政指導）です。項目は事業者の種類ごとに違います
3. 「検索」を押すと、結果が1ページに10件ずつ出ます。10件より多いときは、ページ送りで移ります
4. 結果の「概要」「詳細」のボタンで、処分の内容を読みます

事業者名は部分一致で、略称でも探せますが、入力できるキーワードは1つで、50文字以内です。表示されないときは、正式な名称を入れ直します。すべての情報を見たいときは、条件を全部「リセット」してから「検索」を押します。

### サイトの注意事項

サイトの「ご利用にあたっての注意事項」には、次のことが書かれています。

- 掲載は、最近5年分の行政処分等の情報です（宅地建物取引業者、建設業者の画面で確認）
- 情報は、概ね1か月に1度更新されます
- 宅地建物取引業者の画面には、一部の府県は県のサイトで公開しているため、そちらを確認するよう案内があります
- 建設業者の情報は、各担当部局が公告している内容と異なる場合は、後者が優先されます
- 掲載情報を、無断で転載や改変することはできません

## 消費者庁・都道府県の公表

訪問販売、電話勧誘、通信販売などに関する処分は、消費者庁の「特定商取引法ガイド」の[執行事例の検索](https://www.no-trouble.caa.go.jp/search/)で調べられます。国と都道府県の執行事例が対象で、原則として、処分日が属する年度の翌年度の開始から5年を経過するまでの事例を検索できます。

絞り込みの条件は、事業者名、処分内容、取引類型（訪問販売、通信販売、電話勧誘販売など）、商品・役務、違反行為、処分行政庁、適用条項、処分日です。突然訪ねてきたリフォームや点検の業者について、契約の前後に確かめるときに向いています。

ほかにも、分野ごとの公表があります。

- 労働基準関係法令に違反した企業の公表は、[厚生労働省](https://www.mhlw.go.jp/kinkyu/151106.html)が公表事案として載せています
- 金融に関する処分は、[金融庁の行政処分事例集](https://www.fsa.go.jp/status/s_jirei/kouhyou.html)にあります
- 旅行業者への処分は、[観光庁のページ](https://www.mlit.go.jp/kankocho/page06_000172.html)にあります

業者の名前が同じ会社かどうかを確かめたいときは、国税庁の[法人番号公表サイト](https://www.houjin-bangou.nta.go.jp/)で、本店の所在地と法人番号を調べられます。

## 結果の読み方

処分の記録が見つかったら、次の点を読みます。

- **処分の日付**: 数年前か、最近か
- **処分の種類**: 指示、営業や業務の停止、免許や許可の取り消しなど、法律ごとに種類が違います
- **理由**: たとえば、契約書面の不備や、事実と違う説明など、何に違反したのかを読みます。自分が頼もうとしている内容と関係があるかを見ます
- **処分した役所**: 国か、都道府県か
- **いまも同じ営業をしているか**: 社名や所在地が変わっていることがあります

処分の記録がない場合も、優良な業者という意味ではありません。処分は、違反が行政に確認されて公表の基準を満たしたものだけです。新しい会社や、工事の規模が小さく許可が要らない場合は、そもそもこのサイトに載りません。許可番号や登録番号の有無、契約書面の内容、複数社の見積もりも合わせて確かめてください。

契約でトラブルになりそうなときや、判断に迷うときは、消費者ホットライン[188](https://www.caa.go.jp/policies/policy/local_cooperation/local_consumer_administration/hotline/)に電話すると、最寄りの消費生活相談窓口につながります。訪問販売などの契約には、一定の期間内なら契約を解除できるクーリング・オフの制度がありますが、条件は契約ごとに違うので、相談窓口で確かめてください。

## 近所の処分を地図で見る

業者の名前が分かっているときは、ここまでの方法で調べられます。一方で、「このあたりでどんな処分があったのか」は、1つずつ調べる方法では分かりません。ここからは自社アプリの紹介です。motytools（このサイトの運営者）が作っているiPhoneアプリ「[まちの安全マップ](/machi-anzen-map/)」は、国土交通省、消費者庁、観光庁、金融庁、厚生労働省（各都道府県労働局）、都道府県・市が公表した事業者への処分4,633件を、法人・団体に限って地図に載せています。

[[app]]

住所や駅名を入れると、その周り半径500mと1kmの処分の件数が、出典つきで出ます。処分内容や理由の要約、公表元のページへのリンクも見られます。会員登録はいりません。

できないことは次のとおりです。

- 個人事業主は載せていません。個人名を出さないためです
- 公表されていない処分や、掲載期間が過ぎた処分は載りません。出典ごとの掲載期間の範囲で集めています
- 件数が0件でも、問題がない業者という意味ではありません
- 業者の名前で調べる機能ではないので、特定の会社を確かめるときは、国交省などの検索サイトを使ってください

アプリは無料（広告あり）で、広告を消すのは買い切りです。Web版は[行政処分の地図](https://motytools.com/anzen/shobun/)から見られます。

食中毒の公表の見方は[食中毒の速報はどこで見る？](/guide/shokuchudoku-joho/)に、引っ越し先の調べ方の全体は[引っ越し先の治安の調べ方](/guide/hikkoshi-chian-shirabekata/)にまとめました。
