ハンドメイドの確定申告が必要かどうかは、**売上ではなく所得（売上から必要経費を引いた額）**で決まります。会社員など給与をもらっている人は、給与以外の所得が年間20万円を超えると所得税の確定申告が必要になります。20万円以下でも、住民税の申告は別に必要です。

この記事は、国税庁のタックスアンサー（令和8年4月1日現在法令等）などの公式情報を、2026年10月12日に確認してまとめました。税金の判断は人によって変わるため、迷うときは税務署や税理士に相談してください。

## 結論：判断するのは「売上」ではなく「所得」

所得は次の式で出します。

> 所得 ＝ 総収入金額（売上） − 必要経費

ハンドメイドの必要経費には、売れた作品の材料費（売上原価）、販売手数料、発送の送料、梱包資材などが入ります（[国税庁 No.1350 事業所得の課税のしくみ](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1350.htm)）。同じ売上でも、経費が多ければ所得は小さくなります。

申告が必要になる場面は、立場で変わります。基本のルールは次の2つです。

- **給与をもらっている人**: 給与を1か所から受け、全部が源泉徴収されている場合、給与・退職以外の所得の合計が20万円を超えると申告が必要（[国税庁 No.1900](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1900.htm)）
- **それ以外の人**: その年の所得の合計が所得控除の合計を超え、その超えた分に税額が出る場合は申告が必要（[国税庁 No.2020](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2020.htm)）

「売上が20万円以下だから」ではありません。売上が30万円でも経費で所得が13万円なら、会社員の所得税の基準（20万円）以下です。

## 立場別の早見表

| 立場 | 所得税の確定申告 | 住民税の申告 |
|---|---|---|
| 会社員（給与1か所） | 副業の所得が20万円を超えると必要 | 20万円以下でも必要（確定申告をすれば不要） |
| 専業主婦（主夫） | 所得が所得控除を超えて税額が出れば必要 | 自治体の案内で確認 |
| 学生 | 同上（給与があれば会社員に近い扱い） | 自治体の案内で確認 |
| 個人事業主 | 同上。青色申告なら控除あり | 確定申告をすれば不要 |

### 会社員

年末調整を受けている会社員で、給与を1か所から受けている場合、ハンドメイドなど給与以外の所得の合計が20万円以下なら、所得税の確定申告は不要です。20万円を超えると必要になります。

次のような場合は、20万円の基準とは別の扱いになります。詳しくは国税庁のNo.1900を見てください。

- 給与を2か所以上から受けている
- 医療費控除などで税金を取り戻すために申告する（この場合は申告すれば還付される）

インターネットのフリマアプリを使った個人取引の所得は、一般的に雑所得になると国税庁は案内しています（[国税庁 No.1906](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1906.htm)）。国税庁は、生活の用に供している資産（古着や家財など）の売却による所得は非課税と案内しています。販売を目的に作った作品を売り続ける場合は、これとは別に、営利を目的とした継続的な副業として、業務に係る雑所得か事業所得かの区分を判断することになります。迷う場合は税務署に相談してください（[国税庁 No.1500](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1500.htm)）。

会社員の給与の手取りの目安は、[手取り計算ツール](/tedori/)で見られます。副業を足した税金までは計算しません。

### 専業主婦（主夫）

給与がない人には、20万円の特例は当てはまりません。所得から所得控除（基礎控除など）を引いて税額が出るかどうかで判断します。基礎控除の金額は年分によって変わり、令和7年分から見直されています。金額の表は[国税庁 No.1199](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1199.htm)で確認してください。

もう1つ気にする人が多いのが、配偶者の扶養に関する基準です。所得税では、配偶者控除の対象になる配偶者の合計所得金額が、令和7年分は58万円以下、令和8年分は62万円以下とされています（令和8年分の金額は令和8年12月1日に施行。[国税庁 No.1191](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1191.htm)）。超えても配偶者特別控除が段階的に受けられる範囲があります。**健康保険の扶養は税とは別の基準**なので、加入先の健康保険組合や自治体に確認してください。

### 学生

親の扶養に入っている学生は、所得税の扶養控除の要件に注意します。扶養親族の合計所得金額は、令和7年分は58万円以下、令和8年分は62万円以下です（[国税庁 No.1180](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1180.htm)）。年末に19歳以上23歳未満の人は特定扶養親族として、親は63万円の控除を受けられます。学生の所得が超えると、親の税金が変わります。

アルバイトの給与がある学生は、給与の源泉徴収の状況によって会社員と同じ20万円の基準が使える場合があります。本人の申告が必要かどうかは、所得控除との関係で決まります。

### 個人事業主

開業届を出して事業としてハンドメイドを売っている人も、基本の考え方は同じです。所得が所得控除を超えて税額が出れば申告が必要で、20万円の特例は給与所得者向けです。

青色申告を選ぶと、最大65万円・55万円・10万円の青色申告特別控除が受けられます（[国税庁 No.2072](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2072.htm)）。承認申請書は、原則として青色申告をしようとする年の3月15日まで、新しく開業した場合は開業から2か月以内に出します（[国税庁 No.2070](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2070.htm)）。

## 20万円以下でも住民税の申告は必要

所得税の20万円の特例は、住民税には当てはまりません。名古屋市の案内では、市民税・県民税には所得税のような申告の省略範囲がなく、原則としてすべての所得を申告する必要があるとされています。給与所得者で給与以外の所得が20万円以下の場合も、市民税・県民税の申告が必要です。所得税の確定申告をした場合は、改めて住民税の申告をする必要はありません（[名古屋市の案内](https://www.city.nagoya.jp/kurashi/zeikin/1035069/1012012/1012022/1033974/1012026.html)）。

自治体によって細かい扱いが違うことがあるので、住んでいる市区町村の税務窓口にも確認してください。

## 所得の計算例

架空の例で、1年間の所得を計算します。

| 項目 | 金額 |
|---|---|
| 売上（総収入金額） | 300,000円 |
| 売上原価（期首0円＋仕入れ95,000円−期末の棚卸し15,000円） | 80,000円 |
| 販売手数料 | 32,000円 |
| 送料（自己負担） | 38,000円 |
| 梱包資材 | 10,000円 |
| 道具（1個10万円未満） | 8,000円 |
| 経費の合計 | 168,000円 |
| 所得（売上−経費） | 132,000円 |

検算: 80,000 ＋ 32,000 ＋ 38,000 ＋ 10,000 ＋ 8,000 ＝168,000円。300,000 − 168,000 ＝132,000円です。

売上は30万円ですが、所得は13.2万円なので、給与1か所の会社員なら20万円以下です。ほかに申告が必要になる事情がなければ、国税庁の基準では所得税の確定申告は不要の範囲で、住民税の申告は必要です。

材料の仕入れ95,000円を全額経費にすると、経費は183,000円、所得は117,000円になり、15,000円少なく出てしまいます。売上原価は、年末に残った材料を引く算式で計算します（[国税庁 青色申告の決算の手引き](https://www.nta.go.jp/taxes/shiraberu/shinkoku/tebiki/2025/pdf/025.pdf)）。やり方は[ハンドメイドの棚卸しのやり方](/guide/handmade-tanaoroshi/)で説明します。経費に入るものは[ハンドメイドの経費になるもの一覧](/guide/handmade-keihi/)にまとめました。所得を見込んだ値付けは、[ハンドメイドの値段の決め方](/guide/handmade-nedan-kimekata/)の逆算式で考えられます。

## 申告が要らなくても記録は残す

申告が不要でも、記録は残してください。理由は3つあります。

- 住民税の申告や、扶養の判定で、所得の金額を求められる
- 事業所得などがある人は、所得税の申告が不要でも、記帳と帳簿・書類の保存の制度の対象になる。帳簿は7年、請求書や領収書などは5年の保存が必要（[国税庁 記帳・帳簿等の保存について](https://www.nta.go.jp/taxes/shiraberu/shinkoku/kojin_jigyo/index.htm)）
- 売れ行きが伸びて、あとから申告が必要になったときに、遡って集計できる

残す記録は、売れた日、販路、売上、販売手数料、送料と、材料の仕入れ（日付・店・金額）です。簡易な記帳として、日々の合計をまとめて書く方法も認められています。売上は[ハンドメイドの売上管理表の作り方](/guide/handmade-uriage-kanri/)の形で残せます。

表の管理が負担なら、このサイトの運営者（motytools）が作っているiPhoneアプリ「[つくログ](/apps/tsukulog/)」でも記録できます。
