インスタの保存、スクショ、レシピサイトのお気に入り、冷蔵庫に貼った紙の切り抜き。レシピがあちこちに散らばると、「あれを作ろう」と思った日に見つかりません。この記事は、散らばったレシピを1か所にまとめる手順を、1週間で終わる形で説明します。

## まず「どこにレシピがあるか」を書き出す

整理を始める前に、置き場所を数えます。メモアプリでも紙でも構いません。次の表を、自分の分で埋めてください。

| 置き場所 | だいたいの数 | 探しやすさ | よく作る？ |
|---|---|---|---|
| インスタの保存済み | 　件 | 文字で探せない | |
| TikTokのお気に入り | 　件 | 動画を開いて確かめる | |
| スクショ（写真アプリ） | 　枚 | 写真の検索で探す | |
| レシピサイトのお気に入り・ブックマーク | 　件 | サイトごとに別 | |
| 紙（本、切り抜き、ノート） | 　点 | 目で探す | |
| 頭の中（何度も作る定番） | | | |

数は正確でなくて構いません。「100件以上」でも「10件くらい」でも、どこが一番多いかが分かれば十分です。一番多い場所が、整理の優先順位の先頭になります。

## 集める場所を1つに決める

### 紙ならファイル、スマホならアプリ

集め先は、普段の自分の行動で決めます。

- 台所でスマホを見ながら作る人は、スマホのアプリかメモ
- 紙の本や切り抜きが中心で、台所で紙を広げる人は、ファイルかノート

スマホなら、メモアプリでも、レシピ専用アプリでも構いません。スマホで自分のレシピ帳を作る手順は、[自分だけのレシピノートをスマホで作る方法](/guide/recipe-note-app/)に書きました。

### 全部を移さなくていい

全部のレシピを1か所に移す必要はありません。移す基準は次のとおりです。

- 作ったことがあって、また作る → 移す
- 作ったことはないが、近いうちに作りたい → 移す
- それ以外 → 元の場所に置いたままにする

インスタの保存済みや、ブックマークの中の「いつか」のレシピは、そのままで構いません。移すのは、作る気のあるレシピだけです。

## 分類は3〜5個から始める

分類は、最初は少なくします。例は次のとおりです。

- 主菜
- 副菜・汁物
- お弁当
- 作り置き
- 休日のごちそう

増やしすぎない理由は、分類が多いほど「どこに入れるか」を毎回考えることになり、入れるのが面倒になるからです。件数が増えて、1つの分類に30件以上たまって探しにくくなったら、そのときに「主菜」を「鶏肉」「豚肉」「魚」に分けます。

もう1つ、「作ったことがある」「いつか作る」の2段の印を付ける考え方があります。レシピの横に印を付けるだけで、「今日は定番から選ぼう」「新しいのに挑戦しよう」と選べます。分類を増やさずに、探しやすさが上がります。

## 残すか捨てるかの基準

整理で止まる一番の理由は、捨てる判断ができないことです。次の質問を、レシピごとに1つだけ自分に聞いてください。

> 今から1か月以内に、作る予定があるか

「ある」なら残します。「ない」なら、元の場所に置いたまま、移さずに終わります。消す必要はありません。ただ、集め先には入れません。

スクショが多い人は、不要な分の減らし方を[レシピのスクショを整理する方法](/guide/recipe-screenshot-seiri/)にまとめています。インスタの保存済みが多い人は、[インスタの保存済みを整理する方法](/guide/instagram-hozon-seiri/)を先に読むと進めやすくなります。

## これから増えるレシピの入れ方を決める

過去の分の整理より、これから入ってくる分の入口を1つにするほうが、効果が長く続きます。入口が決まっていないと、整理しても、新しく見つけたレシピがまた別の場所に散らばるからです。

入口のルールは、1行で決めます。

- 作りたいレシピを見つけたら、すぐに集め先へ入れる
- とりあえずの保存（インスタの保存など）は、週に1回、集め先へ移すか、そのままにするか決める

[[app]]

SNSとレシピサイトの分は、アプリに集めておくと、入口を共有ボタンの1操作にできます。当サイト運営者（motytools）が作っているiPhoneアプリ「[レシピスクラップ](/recipescrap/)」は、インスタやTikTok、レシピサイトの投稿を、共有ボタンから取り込み、材料と手順だけの形で保存します。保存したレシピは、料理名でも材料名でも検索できます。取り込みは月10件まで無料です。

使える範囲を先に書いておきます。取り込めるのは、共有ボタンやURLで渡した投稿・ページの文章で、紙や写真、スクリーンショットからの取り込みはできません。家族との共有もありません。Androidでは使えません。紙のレシピは、よく作るものを撮るか、別の方法で残してください。

ほかのアプリも含めて選びたいときは、[レシピ保存アプリの比較](/guide/recipe-hozon-app-hikaku/)を見てください。レシピサイトのブックマークの扱いは、[レシピのブックマーク管理術](/guide/recipe-bookmark/)にまとめています。

## 1日10分×1週間で終わる進め方

1日10分で進める例です。

| 日 | やること |
|---|---|
| 1日目 | 置き場所を表に書き出す。集め先を1つ決める |
| 2日目 | 入口のルールを決める（見つけたらすぐ集め先へ） |
| 3日目 | インスタ・TikTokから、作る予定のレシピを5件移す |
| 4日目 | スクショから、作る予定のレシピを5件移す |
| 5日目 | レシピサイトのブックマークから、5件移す |
| 6日目 | 紙のレシピから、よく作るものを3点撮る |
| 7日目 | 分類を見直す。3〜5個に収まっているか確かめる |

1週間で全部は終わらなくて構いません。「今週作る予定の分」と「入口」が決まれば、整理の目的は達成できています。残りの分は、作りたくなったときに移します。
