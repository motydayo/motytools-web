不動産所得の確定申告で時間がかかるのは、申告書を書く作業より、1年分の家賃収入と経費を集計し直す作業です。この記事では、申告が必要になる条件、白色と青色の違い、そろえる書類、1年分の集計の手順、申告書を作る方法を順に説明します。税金の判断は個別の事情で変わるため、断定はせず、国税庁の案内で確認できたことだけを書きます。最終的な判断は、税務署か税理士に確認してください。

## 不動産所得の確定申告が必要な人

不動産所得は、アパートや駐車場などを貸して得た所得です。所得は、収入金額から必要経費を引いた金額を指します。

会社員など、給与を1か所から受けている人は、国税庁の[タックスアンサーNo.1900](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1900.htm)で、給与所得と退職所得を除く各種の所得の合計額が20万円を超える場合に、確定申告が必要とされています（2026年10月12日に確認。ページの基準は令和8年4月1日現在の法令等）。ここでいう20万円は収入ではなく所得です。家賃収入が20万円を超えていても、経費を引いたあとの所得が20万円以下ならこの基準には当たりませんが、そのほかの条件もあるため、ページ全体を確認してください。

給与所得がない人や、年金で暮らす人の判定は、控除の額などが関わります。年分によって数字が変わるため、国税庁の最新の案内を確認するか、税務署に相談してください。所得税の申告が不要でも、住民税の申告が必要になる場合があるので、お住まいの市区町村にも聞いてください。

申告の期間は、原則として翌年の2月16日から3月15日までです（[No.2020](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2020.htm)）。

## 白色申告と青色申告

申告には、白色申告と青色申告があります。どちらでも、不動産所得があれば帳簿をつけ、書類を保存することが必要です（[No.2080](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2080.htm)）。違いは、青色申告では特別控除などの特典がある一方で、事前の手続きと所定の帳簿が必要な点です。

| | 白色申告 | 青色申告 |
|---|---|---|
| 事前の届出 | 不要 | 青色申告承認申請書の提出が必要 |
| 帳簿 | 簡易な方法でよい | 簡易帳簿または正規の簿記 |
| 特別控除 | なし | 最高10万円、事業的規模なら最高55万円または65万円 |
| 帳簿書類の保存 | 帳簿7年、請求書や領収書などの書類5年 | 帳簿7年、書類は種類により7年または5年 |

特別控除の区分と要件は、国税庁の[No.2070](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2070.htm)と、冊子「帳簿の記帳のしかた（不動産所得者用）」（[PDF](https://www.nta.go.jp/taxes/shiraberu/shinkoku/kojin_jigyo/kichou07.pdf)、令和8年5月1日現在の法令等）で確認しました。冊子によると、事業的規模でない不動産貸付業の青色申告者は最高10万円、事業的規模の人は、正規の簿記で記帳して決算書を添付すれば最高55万円、さらに優良な電子帳簿の保存かe-Taxでの申告をすれば最高65万円です。

事業的規模の目安は、[No.1373](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1373.htm)に、貸間やアパートで独立した室数がおおむね10室以上、独立した家屋でおおむね5棟以上と書かれています。自分が当てはまるかは、税務署か税理士に確認してください。

青色申告の承認申請は、始めようとする年の3月15日まで（その年の1月16日以後に新たに業務を始める場合は、始めた日から2か月以内）に提出します。

## そろえる書類

申告の前に、次の書類を1か所にまとめておくと、集計が進みます。物件や年によって必要な書類は変わるので、目安として使ってください。

| 区分 | 書類の例 |
|---|---|
| 収入 | 賃貸借契約書、家賃の入金記録（通帳やネットバンキングの明細）、更新料や礼金の記録 |
| 経費 | 修繕や管理の領収書・請求書、管理会社の精算書、損害保険料の証明 |
| 税金 | 固定資産税・都市計画税の納税通知書 |
| 借入 | 借入金の返済予定表、年間の利子の額がわかる書類 |
| 減価償却 | 建物の取得時の売買契約書、前年までの償却の記録 |
| 本人確認 | マイナンバーと本人確認の書類（提出方法により異なります） |

借入金は、返済額のうち利子だけが経費になり、元本の部分は必要経費になりません（国税庁の冊子「帳簿の記帳のしかた」の一般的な必要経費の一覧による）。返済予定表の「元本」と「利子」の列を分けて見てください。

## 家賃収入と経費を1年分集計する手順

集計は、1月1日から12月31日までの1年分を、物件ごとに分けて行います。

### 1. 家賃収入を月ごとにそろえる

国税庁は、契約や慣習で支払日が決まっている賃貸料は、その支払日に収入として計上するとしています（[No.1376](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1376.htm)）。記帳の冊子でも、家賃が未収の場合でも未収賃貸料として記載する例が示されています。入金が月や年をまたいだ家賃は、入金日と対象月の両方を記録しておき、どちらで集計すべきかを税務署か税理士に確認してください。

### 2. 礼金・更新料などを加える

更新料や名義書換料などは、総収入金額に含まれます（[No.1370](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1370.htm)）。返還を要しない敷金や保証金も同様です。返還が必要な敷金は、受け取っただけでは収入になりません。

### 3. 経費を項目別に集める

固定資産税、損害保険料、修繕費、管理の手数料、借入金の利子、減価償却費などを、項目ごとに合計します。何が経費になるかの一覧は[不動産所得の経費になるもの一覧](/guide/fudousan-shotoku-keihi/)にまとめています。建物の減価償却費は、計算が必要です。式と例は[不動産の減価償却の計算方法](/guide/genka-shokyaku-fudousan/)と、サイト内の[減価償却の計算ツール](/genka-shokyaku/)で確かめられます。

### 4. 物件ごとの集計表にまとめる

集計表の例です。数字はすべて架空の例で、2物件を持つ大家を想定しています。

| 項目（円） | 物件A（区分1室） | 物件B（アパート6室） |
|---|---|---|
| 家賃収入 | 840,000 | 4,320,000 |
| 更新料 | 0 | 60,000 |
| 収入の合計 | 840,000 | 4,380,000 |
| 固定資産税・都市計画税 | 62,000 | 210,000 |
| 損害保険料 | 11,000 | 36,000 |
| 修繕費 | 0 | 135,000 |
| 管理手数料 | 42,000 | 216,000 |
| 借入金の利子 | 158,000 | 520,000 |
| 減価償却費 | 240,000 | 1,100,000 |
| 経費の合計 | 513,000 | 2,217,000 |
| 差引（収入−経費） | 327,000 | 2,163,000 |

2物件を合わせると、収入は5,220,000円、経費は2,730,000円、差引は2,490,000円です。この差引から青色申告特別控除などを引いたものが、申告書に載る金額の元になります。借入金の元本の返済は、この表に入れていません。

## 申告書を作る方法

申告書の作り方は、大きく3つです。

- **国税庁の確定申告書等作成コーナー**: 画面の案内に沿って入力すると、申告書や青色申告決算書（不動産所得用）が作れます。e-Taxで提出もできます。使い方は[国税庁のサイト](https://www.keisan.nta.go.jp/)で確認してください
- **会計ソフト**: 銀行やカードの明細を取り込み、申告書まで作れるものがあります。各社の機能は[個人大家向け家賃管理アプリ比較](/guide/yachin-kanri-app-hikaku/)で比べています
- **税理士に依頼**: 事業的規模で青色の65万円控除を考える場合や、物件が多い場合は、相談する価値があります

## 来年に向けて日々つけておくこと

申告前の作業を減らすには、毎月の記録が一番効きます。

1. 家賃の入金を、その月のうちに記録する
2. 経費は支払ったときに、物件と項目を付けて記録する
3. 領収書は、撮影して保存し、原本も取っておく。帳簿は7年、書類は5年が基本です（冊子による。種類により異なります）
4. 事業用と私用の口座・カードを分ける

帳簿のつけ方は[不動産所得の帳簿の付け方](/guide/fudousan-shotoku-chobo/)で説明しています。

ここからは自社アプリの紹介です。motytools（このサイトの運営者）が作っているiPhoneアプリ[大家ノート](/ooya-note/)は、毎月の家賃の入金と、修繕費などの支出を、物件ごとに記録できます。借入金の「元本」を選ぶと、経費にならない旨の注意が出て、集計では利子と分けて扱われます。Premiumでは、1年分の家賃収入、経費、手元に残ったお金を物件別にまとめた年間レポートと、収支明細・家賃入金のCSV、年間収支のPDFを書き出せます。

注意点が3つあります。第一に、申告書は作れません。年間レポートは申告の参考にする集計です。第二に、アプリの集計は入金日の年で数えます。前年12月に入った翌年1月分の家賃など、対象月と入金日が違うものは、上の1の考え方との差が出ることがあります。第三に、銀行口座との連携は無く、記録は自分で入力します。無料で使えるのは1物件・3室までで、年間レポートや領収書写真の保存はPremium（月額980円・年額9,800円）です。
