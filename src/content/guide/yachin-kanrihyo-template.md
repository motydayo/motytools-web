家賃の入金をエクセルやスプレッドシートで管理するなら、表は2枚あれば足ります。契約の情報を書く表と、毎月の入金を書く表です。この記事では、その列の並びと、未入金を色で知らせる設定、年間の合計を出す式を、コピーして使える形で載せます。表を作る側の話で、すでにある表をアプリに移す手順は[家賃管理をエクセルからアプリに変える方法](/guide/yachin-kanri-excel-app/)に書いています。

## 家賃管理表に必要な項目

### 契約の情報

1枚目は「契約」という名前のシートにします。1行が1つの契約です。

| 列 | 見出し | 入れるもの |
|---|---|---|
| A | 物件名 | 物件の呼び名 |
| B | 部屋 | 部屋番号 |
| C | 入居者 | 氏名は個人情報なので、書くかどうかを決めておく |
| D | 家賃 | 月額（円） |
| E | 共益費 | 月額（円）。無ければ0 |
| F | 請求額 | =D2+E2 |
| G | 契約開始日 | 日付 |
| H | 更新日 | 次に契約を更新する日 |
| I | 火災保険の満了日 | 日付 |
| J | 保証会社・連帯保証人 | 名称や連絡先のメモ |

### 毎月の入金の情報

2枚目は「入金」という名前のシートです。1行が1つの部屋、列が月です。

| 列 | 見出し | 入れるもの |
|---|---|---|
| A | 部屋 | 「物件名 部屋番号」の形で書く |
| B | 請求額 | 契約シートの請求額 |
| C〜N | 1月〜12月 | 入金があった金額。まだなら空白 |
| O | 年間の入金合計 | 式で出す |
| P | 期日超過の未入金額 | 式で出す |

1行目に見出しを書き、2行目の C〜N に「その月の支払期日」の日付を入れます。たとえば毎月末払いなら、1月は2026/1/31、2月は2026/2/28です。この2行目の日付を未入金の判定に使います。部屋ごとの入金は3行目から書きます。

## 作り方の手順

### 入金チェック欄を月ごとに作る

入金があったら、その月のセルに入金された金額を入れます。日付ではなく金額を入れるのは、次の2つを同じ欄で判定できるからです。

- 空白なら、まだ入金を確認していない
- 請求額より少なければ、一部だけ入金されている

振込手数料を入居者が差し引いて払う場合なども、金額で入れておけば差額が見えます。名義の違いや金額の違いへの対処は、手順をまとめた[家賃の入金確認の方法](/guide/yachin-nyukin-kakunin/)を見てください。

### 未入金を色で知らせる

支払期日を過ぎても空白のセルを赤くします。「条件付き書式」という、条件に合うセルだけ色を変える機能を使います。

1. 入金のセル範囲（たとえば C3:N6）を選ぶ
2. エクセルは「ホーム」→「条件付き書式」→「新しいルール」→「数式を使用して、書式設定するセルを決定」を選ぶ。Googleスプレッドシートは「表示形式」→「条件付き書式」→「セルの書式設定の条件」で「カスタム数式」を選ぶ
3. 次の式を入れて、書式を赤い塗りつぶしにする

```
=AND(C3="",C$2<TODAY())
```

この式は、「C3が空白で、2行目の支払期日が今日より前」という意味です。範囲の左上（ここではC3）を基準に書くと、ほかのセルにも同じ考え方で効きます。

一部入金を黄色にするルールも足せます。同じ範囲に、次の式で2つ目のルールを作ります。

```
=AND(C3<>"",C3<$B3)
```

メニューの名前は、バージョンによって少し違う場合があります。

### 年間の合計を出す

O3に年間の入金合計、P3に期日を過ぎても空白の月の請求額を出します。

```
O3: =SUM(C3:N3)
P3: =SUMPRODUCT(($C$2:$N$2<TODAY())*(C3:N3="")*$B3)
```

P3は「期日が今日より前で、入金が空白の月」の数に請求額を掛けて足す式です。たとえば請求額が72,000円の部屋で、期日を過ぎた9月だけが空白なら72,000円になります。入金が請求額に足りない月の差額は含まれないので、一部入金は色で見分けます。

月ごとの合計は、表の下の行に入れます。

```
C7: =SUM(C3:C6)
C8: =SUMPRODUCT((C$2<TODAY())*(C3:C6=""))
```

C7はその月に入金された合計、C8は期日を過ぎても空白の部屋の数です。

## 更新日・保険の期日も同じ表で管理する

契約シートに、期日までの残り日数の列を足します。たとえば更新日がH2にあるなら、K2に次の式を入れます。

```
K2: =H2-TODAY()
```

残りが180日・90日・30日以下になったら色を変えるルールも、先ほどと同じ条件付き書式で作れます。たとえば次の式です。

```
=AND($H2<>"",$H2-TODAY()<=30)
```

180日、90日、30日の3段階にするなら、ルールを3つ作り、色を黄色、橙、赤と分けます。火災保険の満了日も同じ作りで、60日前と14日前のように決めておけば足ります。期日の考え方は[賃貸契約の更新で大家がやること](/guide/keiyaku-koushin-kanri/)にまとめています。

式の数値は、例の数字（2026年10月12日を今日として、更新日が2027年1月31日なら111日）で検算しています。

## 個人情報を含むファイルの扱い

入居者の氏名や連絡先を書くなら、保管の方法も決めておきます。

- エクセルのファイルは、「ファイル」→「情報」→「ブックの保護」→「パスワードを使用して暗号化」でパスワードをかけられます（メニュー名はバージョンで異なる場合があります）
- Googleスプレッドシートは、右上の「共有」で一般的なアクセスを「制限付き」にして、見られる人を自分だけにします
- 氏名は部屋番号で代用し、連絡先は別の場所に分けると、ファイルが外に出たときの影響を小さくできます
- 管理会社や税理士に渡すときは、必要な列だけにしてから送ります

## 表で管理するときの限界

表の大きな弱点は、開かないと何も教えてくれないことです。色が付く設定をしても、表を開いたときにしか目に入りません。月末に開き忘れれば、遅れの発見も遅れます。

表を使い続けながら対策するなら、期日だけでもiPhoneの標準アプリ「リマインダー」や「カレンダー」に入れておく方法があります。毎月の入金確認日と、更新日の180日前、90日前、30日前を登録します。入力の手間は増えますが、表を開かなくても通知が届きます。

ここからは自社アプリの紹介です。motytools（このサイトの運営者）が作っているiPhoneアプリ[大家ノート](/ooya-note/)は、物件、部屋、契約を登録すると、毎月の家賃チェック表が自動でできます。入金を確認したらタップするだけで、期日を過ぎて未確認の家賃は赤い表示で知らせます。更新日と火災保険の満了日は通知で届きます。エクセルの表を読み込む機能は無いので、物件、部屋、契約は手で登録します。その手順は[家賃管理をエクセルからアプリに変える方法](/guide/yachin-kanri-excel-app/)にまとめています。無料で使えるのは1物件・3室までです。
