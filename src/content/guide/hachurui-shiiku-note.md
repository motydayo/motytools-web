爬虫類の飼育記録は、給餌、体重、脱皮の3つを日付つきで残すところから始めれば足ります。この記事では、そのうえで残しておくと役立つ項目、紙・エクセル・アプリの違い、写真の残し方、続けるコツを順に説明します。

## 記録が役に立つ場面

記録は、世話の「あとから」に効きます。

- 食べないとき：最後に食べた日、そのときの量、体重の動きが分かると、様子を見てよいのか迷う判断がしやすくなります。レオパの場合は[レオパが餌を食べないときに確かめること](/guide/leopa-esa-tabenai/)にまとめています
- 脱皮のとき：前回の脱皮の日が分かれば、次の時期の見当がつきます
- 動物病院にかかるとき：獣医師は、飼育環境や餌、これまでの経過を尋ねます。ボールパイソンの飼育ページ（[PetMD](https://www.petmd.com/reptile/ball-python-care-sheet)、獣医師が確認）では、受診のときに飼育環境、餌、ヒーターやライトの写真や仕様を持っていくよう勧めています
- 譲渡や引き継ぎのとき：渡す相手に飼育の経過が伝わります。くわしくは[爬虫類を譲渡するときの引き継ぎ](/guide/hachurui-joto-hikitsugi/)に書きました

## 残す項目

次の表は、残す項目の例です。すべてを毎日つける必要はありません。

| 項目 | 残す内容 | つける頻度の例 |
|---|---|---|
| 給餌 | 日付、餌の種類、数、食べたか・残したか | 与えるたびに |
| 体重 | グラム単位の数値 | 週に1回など、決めた間隔で |
| 脱皮 | 日付、きれいに脱げたか、皮が残ったか | 脱皮のたびに |
| 排泄 | 日付、便や尿酸の状態 | 気づいたときに |
| 掃除 | 日付、床材を替えたか | 掃除のたびに |
| 温度・湿度 | 暖かい側・涼しい側の温度、湿度 | 時間を決めて、または変化があったときに |
| メモ | 動きが鈍い、尻尾が太ってきたなどの気づき | 気づいたときに |

頻度の欄は、続けやすさを考えた例です。体重を測る間隔に正解はありません。成長が早い幼体は短め、体重が安定した成体は長めにする、という考え方があります。迷ったら、まず週に1回を試して、手間と見え方を見て決めてください。

排泄は、異常があるときに伝えるための記録です。RSPCA（英国の動物福祉団体）のレオパの飼育ガイドは、いつもと違うフンや便秘が体重減少とともに見られる場合は獣医師に診せるよう案内しています（[RSPCA](https://www.rspca.org.uk/adviceandwelfare/pets/other/leopardgecko)、2026年10月12日確認）。

### 数字より推移を残す

体重や温度は、1回の数字では良いか悪いか分かりません。同じ個体の数字が並んだときに、増えている、横ばい、減っているが見えます。そのため、測る条件をそろえるのが大切です。たとえば「朝、餌をあげる前に」と決めておきます。

### 動物病院に見せる記録の整え方

受診の日に、数か月分の記録をそのまま見せても、先生が読み取る時間がかかります。診察前に、次の4点を1枚にまとめておくと伝わりやすくなります。

1. 気になる変化と、気づいた日
2. 直近1〜3か月の体重の推移（日付と数字）
3. 最後に食べた日、餌の種類と量、最後の脱皮とフンの日
4. 温度・湿度とヒーターなどの機器の種類、ケージ全体の写真

PetMDのボールパイソンの飼育ページも、環境や機器の写真や仕様を持参するよう勧めています。症状の写真（脱皮が残った指先、膨らんだお腹など）も、その場で説明しやすい材料になります。

## 紙・エクセル・アプリの違い

| 方法 | よいところ | 弱いところ |
|---|---|---|
| 紙のノート | 世話の場で書ける。費用がかからない | 推移をグラフにしにくい。ケージの近くで汚れる |
| エクセルなどの表計算 | 項目を自由に決められる。グラフが作れる | スマホで入力しにくく、続かなくなりやすい |
| アプリ | 数タップで残せる。一覧や推移が自動でできる | アプリごとに項目や無料の範囲が違う |

飼う数が1〜2匹で、体重と給餌日だけなら、紙でも十分に続きます。数が増えたり、推移を見たくなったりしたら、表計算かアプリに移すと楽になります。

ここからは自社アプリの紹介です。motytools（このサイトの運営者）が作っているiPhoneアプリ「[うちの爬虫類](/reptile-sns/)」は、「＋」を押して種類を選び、保存する3タップで給餌・体重・脱皮を残せます。前回の値が入った状態で開くので、体重なら数字を直すだけです。記録の種類は、ほかに排泄、掃除、温湿度、健康メモがあります。

[[app]]

無料で5匹まで登録でき、記録・投稿・部屋への参加・質問箱は無料で使えます。体重と給餌の推移グラフ、個体の記録をまとめたPDF（個体パスポート）は、月額300円（年額2,400円）のProの機能です。iPhone専用で、Android版はありません。温湿度は手で入力する形で、自動で取り込む機能はありません。アプリの比較は[爬虫類の飼育記録アプリ比較](/guide/hachurui-shiiku-kiroku-app/)にあります。

## 写真の残し方

写真は、文字では残しにくい情報を補います。

- 全体：体型（尻尾の太さ、お腹の張り）が分かる、横から見た1枚
- 脱皮のあと：指先と目のまわりに皮が残っていないかを確かめた1枚
- 環境：ケージ全体、ヒーターの位置、床材。レイアウトを変えるたびに撮ると、変化との関係が追えます
- 同じ角度で定期的に：月に1回ほど、同じ背景で撮ると成長の比較がしやすい

うちの爬虫類では、記録に写真を添えると、そのまま個体のタイムラインの投稿になります。記録ごとに「みんなに見せる」か「自分だけ」かを選べます。住所や部屋の様子が写り込む写真は、公開しないでください。

## 続けるコツ

記録が三日坊主で終わるときは、「1回の手間が大きい」か「見返すタイミングが無い」のどちらかを見直します。

1. 最初は3項目だけにする。給餌、体重、脱皮以外は、必要を感じてから足します
2. 記録する場所を1つに決める。ノートとアプリを両方使うと、どちらかが抜けます
3. 世話の流れに入れる。餌をあげたらすぐ、が最も忘れません
4. 月に1回、見返す日を決める。体重の動きと脱皮の間隔を眺める時間が、続けるごほうびになります
5. 抜けた日があっても埋めようとしない。空白は「記録していない日」であり、失敗ではありません

体重の見方は[レオパの体重の目安](/guide/leopa-taiju-meyasu/)で説明しています。記録を見ていつもと違うと感じたら、飼育書や飼い主どうしの意見は参考にとどめ、爬虫類を診られる動物病院に相談してください。
