家庭の食品を表で管理するなら、列は「品名・数量・保管場所・賞味期限・残り日数・開封日」の6つに、メモ欄を足した7列があれば足ります。残り日数は式で自動計算し、期限が近い行には色を付け、期限の近い順に並べれば、開くだけで「今日食べる物」がわかる表になります。この記事では、エクセルとGoogleスプレッドシートで使える式と手順を、そのままコピーして使える形で説明します。

## 家庭用の管理表に必要な項目

飲食店向けの在庫表は、仕入れ先や原価の列まで持ちますが、家庭では不要です。列を増やすほど入力が面倒になり、続かなくなります。

| 列 | 項目 | 入れる内容 | 例 |
|---|---|---|---|
| A | 品名 | 食品の名前 | 牛乳 |
| B | 数量 | 残っている個数 | 1 |
| C | 保管場所 | 冷蔵庫、冷凍庫、常温のどれか | 冷蔵庫 |
| D | 賞味期限 | パッケージの日付（日付の形で入れる） | 2026/10/15 |
| E | 残り日数 | 式で自動計算する | 3 |
| F | 開封日 | 開けた日。未開封なら空欄 | 2026/10/10 |
| G | メモ | 自由に書く | 小分け、開封済みなど |

D列には、消費期限の食品の日付も入れます。消費期限は過ぎたら食べないほうがよい期限なので、メモ欄に「消費」と書いておくと見分けられます（違いは[消費期限と賞味期限の違い](/guide/shomi-shohi-chigai/)を参照）。パッケージが「2027.03」のように年月だけの表示のときは、その月の末日を入れます。年月の表示は、月末までの期限を表すためです。

完成すると、次のような表になります（日付は例で、2026年10月12日に見たものとします）。

| 品名 | 数量 | 保管場所 | 賞味期限 | 残り日数 | 開封日 | メモ |
|---|---|---|---|---|---|---|
| 豆腐 | 2 | 冷蔵庫 | 2026/10/13 | 1 | | 消費期限 |
| 牛乳 | 1 | 冷蔵庫 | 2026/10/15 | 3 | 2026/10/10 | 開封済み |
| 鶏むね肉 | 1 | 冷凍庫 | 2026/11/20 | 39 | | 小分け |
| ツナ缶 | 5 | 常温 | 2028/03/31 | 536 | | 備蓄 |

## 作り方の手順

1. 1行目に、上の7つの見出しを入力する
2. D列とF列を選び、セルの表示形式を「日付」にする（Googleスプレッドシートは、メニューの「表示形式」の「数字」から日付を選ぶ）
3. 2行目から、食品を1行ずつ入力する。日付は「2026/10/15」のように、スラッシュで区切って打つと日付として認識されます
4. 次の節の式を、E2に入力する

### 残り日数を自動で出す

E2セルに、次の式を入力します。D2が賞味期限のセルです。

```
=IF(D2="","",D2-TODAY())
```

意味は「D2が空欄なら何も表示しない。入っていれば、D2の日付から今日の日付を引く」です。TODAY()は今日の日付を返す関数で、エクセルでもGoogleスプレッドシートでも同じように使えます。入力したら、E2の右下の小さな四角を下へ引っぱって、ほかの行にもコピーします。

上の例の表で計算すると、豆腐は1、牛乳は3、鶏むね肉は39、ツナ缶は536になります。期限を過ぎた食品はマイナスの数になり、-1は「1日過ぎている」という意味です。

注意点が2つあります。

- 結果が「1900/1/3」のような日付の形で出たら、E列の表示形式を「標準」にします。マイクロソフトの公式ヘルプにも、日付どうしの引き算の結果を日数で表示するには、表示形式を「標準」か「数値」にする必要がある、と書かれています。Googleスプレッドシートでは、「表示形式」の「数字」で「自動」を選びます
- TODAY()は、ファイルを開いたときや再計算のたびに今日の日付に更新されます。印刷した紙や、PDFに書き出したものは、その時点の日数のままです

参考：[TODAY 関数](https://support.microsoft.com/ja-jp/office/today-%E9%96%A2%E6%95%B0-5eb3078d-a82c-4736-8930-2f51a028fdd9)（Microsoft サポート）、[TODAY](https://support.google.com/docs/answer/3092984?hl=ja)（Google ドキュメント エディタ ヘルプ）。この記事の式は、サンプルの日付を入れて計算結果を検算しています

### 期限が近い物に色を付ける

残り日数が小さい行に色を付けると、開いた瞬間に目に入ります。「条件付き書式」を使います。

エクセルの場合：

1. 色を付けたい範囲（例：A2からG200）を選ぶ
2. 「ホーム」タブの「条件付き書式」から「新しいルール」を選ぶ
3. 「数式を使用して、書式設定するセルを決定」を選ぶ
4. 数式の欄に次の式を入力し、「書式」で赤系の塗りつぶしを選んで「OK」を押す

```
=AND($E2<>"",$E2<=3)
```

Googleスプレッドシートの場合は、範囲を選んで、メニューの「表示形式」から「条件付き書式」を開き、「セルの書式設定の条件」で「カスタム数式」を選んで、同じ式を入力します。

式の意味は「E列が空欄ではなく、3以下なら」です。期限切れ（マイナス）も3以下に含まれるので、赤く表示されます。$E2のようにEの前にドルマークを付けるのは、列を固定して、行全体を同じ基準で塗るためです。

黄色の「今週中」も作る場合は、ルールをもう1つ追加します。

```
=AND($E2<>"",$E2>3,$E2<=7)
```

2つのルールは条件が重ならないので、順番は気にしなくて構いません。式の動きは、空欄、-1、0、3、7、39の6つの値を入れて確かめています（空欄は塗られず、-1・0・3は赤、7は黄色、39は塗られない）。

参考：[条件付き書式を使用して特定のデータを強調表示する](https://support.microsoft.com/ja-jp/office/%E6%9D%A1%E4%BB%B6%E4%BB%98%E3%81%8D%E6%9B%B8%E5%BC%8F%E3%82%92%E4%BD%BF%E7%94%A8%E3%81%97%E3%81%A6%E7%89%B9%E5%AE%9A%E3%81%AE%E3%83%87%E3%83%BC%E3%82%BF%E3%82%92%E5%BC%B7%E8%AA%BF%E8%A1%A8%E7%A4%BA%E3%81%99%E3%82%8B-fed60dfa-1d3f-4e13-9ecb-f1951ff89d7f)（Microsoft サポート）、[Google スプレッドシートで条件付き書式ルールを使用する](https://support.google.com/docs/answer/78413?hl=ja)

### 期限順に並べる

期限の近い物が上に来ると、上から順に食べるだけになります。

1. 見出しの行を含めて、A列からG列の範囲を選ぶ
2. 「データ」の並べ替え（Googleスプレッドシートは「データ」の「範囲を並べ替え」）で、D列（賞味期限）を昇順にする。見出し行がある設定にする
3. 新しい食品を入力したら、同じ操作をもう一度行う

空欄の行が間にあると、範囲が途中で切れることがあるので、範囲は必ず自分で選びます。メニューの名前はバージョンによって少し違います。

## スマホで見る・家族と共有する

管理表は、家でパソコンの前にいないと見られない点が弱みです。スマホで見るなら、次の方法があります。

- Googleスプレッドシート：スマホ用のアプリで開ける。「共有」から家族を招待すると、同じ表を見たり編集したりできる（権限の設定は下の公式ヘルプを参照）
- エクセル：ファイルをクラウドに保存し、スマホのエクセルアプリで開く

共有の手順は、[Google ドライブのファイルを共有する](https://support.google.com/docs/answer/2494822?hl=ja)（Google ドキュメント エディタ ヘルプ）に説明があります。

ただ、スマホの小さな画面で、品名と日付を毎回打つのは負担が大きいです。**閲覧はスマホ、入力は家のパソコンで**と分けると続きやすくなります。

## 表が続かないときは

表が続かなくなる理由は、たいてい次のどれかです。

- 買い物から帰って、1品ずつ入力するのが面倒になる
- 開かないと期限が来たことに気づけない（表は自分から知らせてくれない）
- 数量が変わっても、書き直しを忘れる

どれも、入力の手間と「知らせてくれない」ことが原因です。表の作り込みを増やしても、解決しにくい部分です。

motytools（このサイトの運営者）が作っているiPhoneアプリ「[ピッと期限](/pitto-kigen/)」は、この2つを減らすための自社アプリです。商品のバーコードを読むと商品名が入り、賞味期限はパッケージの印字をカメラで読み取って入れます。期限が近づくと通知が届くので、表を開く必要がありません。

[[app]]

表との違いも正直に書きます。ピッと期限は、並べ替えや式を自由に組むことはできません。通知は期限の3日前と1日前の朝9時の2回に決まっていて、日にちを変える設定はありません。Android版はなく、全機能が無料ですが画面の下に広告が出ます。表のよさは、列を自由に増やせることと、道具が無料で手に入ることです。

使い分けは、次のようになります。

- 食品が少なく、パソコンを見る習慣がある：表で十分
- 買い置きが多く、外出先でも見たい：アプリ。比較は[賞味期限管理アプリの比較](/guide/shomikigen-kanri-app/)を参照
- 備蓄の食品を回している：[ローリングストックの管理方法](/guide/rolling-stock-kanri/)も参考に

開封した日から数日後、といった日付の足し算は、[日数計算ツール](/days/)の「◯日後・◯日前」でできます。冷蔵庫全体の見直しは、[冷蔵庫の在庫管理のやり方](/guide/reizoko-zaiko-kanri/)にまとめています。
