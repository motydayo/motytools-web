不動産所得のある人は、白色申告でも青色申告でも、帳簿をつける必要があります。この記事では、帳簿が必要な理由と種類、簡易帳簿に書く項目、エクセルでの作り方、記録を楽にする工夫を説明します。内容は、国税庁の冊子「帳簿の記帳のしかた（不動産所得者用）」（[PDF](https://www.nta.go.jp/taxes/shiraberu/shinkoku/kojin_jigyo/kichou07.pdf)、令和8年5月1日現在の法令等）と、タックスアンサーで2026年10月12日に確認した範囲です。控除額などの数字は、申告する年分の国税庁の案内で確認し、迷う点は税務署か税理士に相談してください。

## 帳簿が必要な理由と種類

所得税は、自分で所得を計算して申告する仕組みです。冊子には、事業所得、不動産所得、山林所得を生ずる業務を行う全ての人は、帳簿を備え付け、取引を所定の方法で記録し、一定期間保存することが所得税法で義務付けられていると書かれています。所得税の申告が必要ない人も含みます。

帳簿の種類は、申告の種類で変わります。

| | 白色申告 | 青色申告（簡易帳簿） | 青色申告（正規の簿記） |
|---|---|---|---|
| 帳簿 | 収入と必要経費を記載した帳簿 | 現金出納帳、収入帳、経費帳、固定資産台帳 | 仕訳帳、総勘定元帳などの複式簿記 |
| 特別控除 | なし | 最高10万円 | 事業的規模なら最高55万円または65万円 |
| 保存期間 | 帳簿7年、書類5年 | 帳簿7年、書類は7年または5年 | 同左 |

特別控除の区分は、国税庁の[No.2070](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2070.htm)と冊子で確認しました。事業的規模の目安は、アパートなどでおおむね10室以上、独立した家屋でおおむね5棟以上です（[No.1373](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1373.htm)）。控除の要件は年分ごとに見直されることがあるため、申告する年の案内を確認してください。

青色申告にするには、始める年の3月15日までに承認申請書を出します（新たに業務を始める場合は2か月以内）。白色申告にも記帳の義務があるので、帳簿をつけない選択肢はありません。

## 簡易帳簿に書く項目

冊子には、白色申告の帳簿の記載事項が示されています。収入と経費で、書く内容が違います。

| 区分 | 記載する項目 |
|---|---|
| 収入 | 取引の年月日、事由と相手方の名称、金額。賃貸料、礼金・権利金・更新料、名義書換料などの項目に分ける |
| 経費 | 取引の年月日、事由と支払先の名称、金額。給料賃金、減価償却費、貸倒金、地代家賃、借入金利子、修繕費、管理手数料などの項目に分ける |

経費の項目は、自分の物件の状況に合う名前を付けて構いません。収入は、契約書や領収書の控えで内容を確認できる場合に、事由と相手方を省略して、項目ごとの日々の合計金額だけを書く簡易な方法が認められています。少額の経費も、項目ごとの合計を書けます。

家賃が未収の場合でも、冊子の記載例では、未収賃貸料として記載する形が示されています。入金のタイミングと帳簿に書く日の関係は、税務署か税理士に確認してください。

青色申告の簡易帳簿は、次の4つです（冊子の「備付け帳簿の内容」）。

- **現金出納帳**: 現金や預金の出入りを書く
- **収入帳**: 賃貸料などの収入を書く
- **経費帳**: 経費を項目ごとに書く
- **固定資産台帳**: 減価償却の対象になる資産を書く

現金や預金、クレジットカードは、事業用と私用を区別するようにと、冊子に書かれています。

## エクセルでの作り方

エクセルで簡易帳簿を作るなら、収入と経費を別のシートにします。国税庁のホームページには、帳簿の様式例（不動産所得者用）も用意されています。

### 収入帳のシート

| 列 | 見出し | 入れるもの |
|---|---|---|
| A | 日付 | 入金日、または契約上の支払日 |
| B | 物件 | 物件名 |
| C | 部屋 | 部屋番号 |
| D | 摘要 | 「11月分家賃」「更新料」など。相手方も書く |
| E | 賃貸料 | 家賃と共益費の合計 |
| F | 礼金・更新料 | 金額 |
| G | その他 | 駐車場代など |

家賃の入金は、毎月の入金管理の表をそのまま収入帳にできます。入金確認の表の作り方は[家賃管理表のテンプレートと作り方](/guide/yachin-kanrihyo-template/)にあります。

### 経費帳のシート

| 列 | 見出し | 入れるもの |
|---|---|---|
| A | 日付 | 支払った日 |
| B | 物件 | 物件名 |
| C | 摘要 | 「壁紙補修（◯◯工務店）」など。支払先も書く |
| D | 項目 | 修繕費、租税公課、管理手数料などの固定した項目 |
| E | 金額 | 円 |
| F | 領収書の場所 | 保管した場所や、撮影した画像の名前 |

D列は、入力ミスを防ぐため、リストから選ぶ形（データの入力規則）にしておくと、項目の表記がそろいます。

### 項目別の合計を出す

項目ごとの年間の合計と、月ごとの合計は、次の式で出せます。範囲は、行数に余裕を持たせた固定の範囲にしてあります。

```
修繕費の合計: =SUMIF($D$2:$D$500,"修繕費",$E$2:$E$500)
10月の経費の合計: =SUMIFS($E$2:$E$500,$A$2:$A$500,">="&DATE(2026,10,1),$A$2:$A$500,"<="&DATE(2026,10,31))
物件Aの修繕費の合計: =SUMIFS($E$2:$E$500,$B$2:$B$500,"A",$D$2:$D$500,"修繕費")
```

試しに、物件Aの修繕費が10月20日に135,000円と11月9日に18,000円、物件Aの管理手数料が10月31日に30,000円、物件Bの固定資産税が11月5日に52,000円という4行を入れて計算すると、修繕費の合計は153,000円、10月の経費の合計は165,000円、物件Aの修繕費の合計は153,000円になります。

## 記録を楽にする工夫

帳簿の負担は、年末にまとめてつけようとすると大きくなります。次の工夫で、日々の負担を小さくできます。

1. **収入と経費を分けて、その場で記録する**: 入金を確認したとき、領収書を受け取ったときに、数十秒で済ませる
2. **項目を固定する**: 毎回、項目名を考えない。リストから選ぶ
3. **領収書は日付順に袋やフォルダへ入れる**: 帳簿の「領収書の場所」の列と合わせる
4. **口座とカードを分ける**: 賃貸に使う口座を1つ決めると、明細がそのまま経費の確認に使える
5. **保存期間を覚えておく**: 帳簿は7年、書類は5年が基本（青色申告では書類により7年）

ここからは自社アプリの紹介です。motytools（このサイトの運営者）が作っているiPhoneアプリ[大家ノート](/ooya-note/)は、家賃の入金と、修繕費などの支出を、物件ごとに記録できます。記録した内容は、年間の収支としてまとめられます（年間レポートと、収支明細・家賃入金のCSV書き出しはPremium）。領収書の写真を添付できるのもPremiumです。

注意点があります。アプリの記録が帳簿の要件を満たすかどうかは、このサイトでは判断できません。記録は、申告の参考にする集計の材料として使い、帳簿そのものの扱いは、税務署か税理士に確認してください。確定申告書の作成もできません。無料で使えるのは1物件・3室までで、Premiumは月額980円・年額9,800円です。
