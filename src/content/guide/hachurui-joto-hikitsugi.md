飼えなくなった爬虫類は、購入元や専門店、飼育仲間など、命を引き継げる相手を探して相談するのが第一歩です。捨てたり野外に放したりすることは認められていません。この記事では、まず相談できる先、渡す情報、法令の注意、記録のまとめ方を説明します。

## まず相談できる先

次の順に当たってみてください。

1. 購入元の店やブリーダー（繁殖者）：引き取りや、次の飼い主を一緒に探してくれることがあります。対応は店によって異なります
2. 爬虫類を扱う専門店：引き取りの可否や条件は店ごとに違うので、先に問い合わせます
3. 飼育仲間、知人：種類の飼育に慣れた人に引き継げるのが理想です
4. 自治体の動物愛護の担当窓口：自治体の案内は犬や猫の引き取りを中心にしているものが多く、爬虫類の扱いは自治体で違います。問い合わせれば、対応先を教えてもらえることがあります

一人で抱え込むより、早めに相談するほうが、選べる道が広がります。体調に不安がある個体は、先に爬虫類を診られる動物病院で診察を受けてください。

## 譲渡先に渡す情報

引き継ぎで困りやすいのは、情報の抜けです。紙1枚でもまとめて渡します。次は引き継ぎシートに入れたい項目の例です。

| 分類 | 項目 |
|---|---|
| 基本 | 種類、モルフ（体色や模様の系統）、性別、生年月日または推定月齢、迎えた日、入手元 |
| 餌 | 餌の種類とサイズ、頻度、最後に食べた日、食べ方の癖、サプリメントを与えているか |
| 体重 | 直近数か月の推移と、普段の体型 |
| 脱皮・排泄 | 最後の脱皮の日、脱皮がうまくいかなかった経験、最後のフンの日 |
| 環境 | ケージの大きさ、温度（暖かい側・涼しい側・夜）、湿度、ヒーター、ライト、床材、隠れ家、掃除の頻度 |
| 健康 | 病歴、通院先、薬、寄生虫の検査結果、気になっている症状 |
| 性格・扱い | 触られるのが苦手か、かむことがあるか、脱走の癖 |
| 繁殖 | メスなら産卵歴や、卵を持っている可能性 |
| 用品 | ケージ、ヒーター、秤などを一式つけるか |

特に、最後に食べた日と餌の内容は必ず伝えます。環境が変わると、食べ方が変わる個体がいます。爬虫類専門誌Reptiles Magazineのヤモリの相談への回答で、獣医師は、移動中に体が冷えたり強いストレスを受けたりすると、あとで調子を崩しやすいと説明しています（[Reptiles Magazine](https://reptilesmagazine.com/healthy-gecko-not-eating/)）。輸送は、手渡しを基本に考え、冷やさないようにしてください。

シートには、自分の住所や連絡先を書かず、やり取りの方法は譲渡先と別に決めてください。

## 気をつけること（法令・マナー）

### 捨てない、放さない

動物愛護管理法では、人が飼っている哺乳類・鳥類・爬虫類は「愛護動物」にあたります。愛護動物を遺棄（捨てること）すると、1年以下の拘禁刑（2025年6月の刑法改正までは懲役）または100万円以下の罰金の対象になります（[広島市](https://www.city.hiroshima.lg.jp/living/pet-doubutsu/1021301/1026248/1023101.html)）。罰則は令和元年の改正で引き上げられ、令和2年6月1日に施行されています（[環境省](https://www.env.go.jp/nature/dobutsu/aigo/1_law/revise_r01.html)）。

野外に放すことも、捨てることにあたるおそれがあります。外来の種類を放すと、地域の生き物にも影響が出ます。

### 営利で譲る場合は登録が必要なことがある

環境省によると、営利を目的に爬虫類などの販売、保管、貸出しなどを業として行う場合は、第一種動物取扱業の登録が必要です（[環境省](https://www.env.go.jp/nature/dobutsu/aigo/1_law/trader.html)、2026年10月12日確認）。自分で動物を持たない代理販売のような形でも対象になります。

環境省のページには、無償譲渡や個人間のやり取りの扱いは書かれていません。繰り返し譲る、利益を目的にしていると受け取られる、といった場合は、登録が必要かどうかを、都道府県や政令指定都市の動物愛護の担当窓口に事前に確認してください。

### 種類による規制

ワニ、マムシなどの特定動物は、人に危害を加えるおそれがあるとして、令和2年6月1日から、愛玩目的の飼養が禁止されています（[環境省](https://www.env.go.jp/nature/dobutsu/aigo/1_law/danger.html)）。特定動物の譲渡や引き継ぎは、許可の範囲に関わるため、自治体に確認が必要です。ほかに外来生物法の規制を受ける種類もあります。

### 譲渡先を選ぶとき

- 相手がその種類の飼育経験や設備を持っているか、環境の写真や説明で確かめる
- 手渡しで会い、元気な状態を一緒に確認する
- 引き渡す日と、引き渡す内容を書面やメッセージで残す
- 感染症の予防のため、触れたあとは手を洗う。厚生労働省は、ハ虫類は見た目に症状がなくてもサルモネラを持っていることがあるとしています（[厚生労働省](https://www.mhlw.go.jp/bunya/kenkou/kekkaku-kansenshou19/salmonella_qa.html)）。子どもや高齢者、免疫が弱い人のいる家庭への譲渡では特に注意が必要です

SNSで譲渡先を探す場合の注意は、[爬虫類の飼い主がつながるSNS](/guide/hachurui-sns/)にもまとめました。

## 記録をまとめて渡す

飼育の経過は、記録があるほど正確に伝わります。項目の考え方は[爬虫類の飼育記録のつけ方](/guide/hachurui-shiiku-note/)にあります。紙のノートやメモなら、コピーかスキャンを渡します。

ここからは自社アプリの紹介です。motytools（このサイトの運営者）が作っているiPhoneアプリ「[うちの爬虫類](/reptile-sns/)」には、個体のプロフィールと記録をまとめた「個体パスポート」をPDFで書き出す機能があります。譲渡時の引き継ぎ資料としても使えます。

[[app]]

個体パスポートのPDFは、月額300円（年額2,400円）のProの機能で、無料プランでは使えません。個体の状態は「譲渡済み」にできます。個体を売買したり、譲渡先を探したりする機能やダイレクトメッセージの機能はありません。iPhone専用で、Android版はありません。

PDFは、項目が足りないときは追記して渡してください。餌のサイズや環境の細かい点は、別に書き足したほうが伝わります。アプリの比較は[爬虫類の飼育記録アプリ比較](/guide/hachurui-shiiku-kiroku-app/)にあります。

どうしても自分では引き継げないとき、飼育に不安があるときは、一人で決めず、動物愛護の担当窓口や爬虫類を診られる動物病院に相談してください。
