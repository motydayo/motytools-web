個人でピアノを教えている講師の確定申告では、支出を**「経費になりうる」「按分（私用と仕事で分ける）」「減価償却（数年に分ける）」「経費にならない」「要相談」**の5つに分けて考えると整理しやすくなります。この記事では、楽譜・調律・ピアノ本体・自宅教室の家賃など29項目を、国税庁の案内を出典にして一覧にしました。印刷用のPDFと、金額を入れて集計できるExcelもあります。

この記事は一般的な情報です。数字と制度は2026年11月11日に国税庁のタックスアンサー（令和8年4月1日現在法令等）で確かめました。個別の支出が経費になるかどうかは、使い方や金額で変わります。最終的には税務署か税理士に確認してください。

## 経費になるかを分ける3つの考え方

国税庁の[No.2210 必要経費の知識](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2210.htm)（2026年11月11日確認）から、ピアノ講師に関係する考え方を3つ抜き出します。

1. **収入を得るための費用であること**。レッスンや指導の準備、教室の運営に使った費用が対象です。
2. **その年に債務が確定していること**。支払ったかどうかではなく、12月31日までに「支払う義務が決まり、物やサービスを受け取り、金額がわかる」状態かで、どの年の経費かが決まります。
3. **私用と仕事が混ざる費用は、仕事の部分だけ**。家賃・水道光熱費のような費用は「家事関連費」と呼ばれ、仕事に直接必要だった部分を明らかに区分できる金額だけが必要経費になります。

なお、ピアノ教室の所得が「事業所得」になるか「雑所得」になるかで、使える制度が変わります。たとえば青色申告は、事業所得・不動産所得・山林所得がある人が対象です（[No.2070 青色申告制度](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2070.htm)、同日確認）。自分の所得がどちらに当たるかは、規模や続け方で変わるので、税務署に確認してください。

## ピアノ講師の経費一覧

よく出てくる項目を表にしました。区分は目安です。「経費になりうる」は、仕事に使った分であれば経費として扱われる可能性がある、という意味です。

| 項目 | 区分の目安 | 考え方 |
|---|---|---|
| 楽譜・教本・ワーク | 経費になりうる | 指導に使う分。趣味の演奏用とは分ける |
| シール・文具・コピー代 | 経費になりうる | レッスンで使う消耗品 |
| 調律・修理 | 経費になりうる | 家族も弾くピアノなら按分を考える |
| ピアノ・電子ピアノ（10万円未満） | 経費になりうる | 使い始めた年に全額 |
| ピアノ（10万円以上） | 減価償却 | 金額と申告の方法で扱いが変わる（次の章） |
| 自宅教室の家賃・電気・ガス・水道 | 按分 | 部屋の面積や使う時間で、仕事の部分を分ける |
| 電話・インターネット | 按分 | 私用と仕事の割合で分ける |
| 貸しスタジオ・会場の利用料 | 経費になりうる | レッスンのために借りた分 |
| 指導法の講座・セミナーの参加費 | 経費になりうる | 指導とのつながりを説明できるもの |
| 自分が先生に習うレッスン代 | 要相談 | 趣味の習い事との線引きが分かれやすい |
| 発表会の会場費・印刷・記念品 | 経費になりうる | 集めた参加費は収入として記録する |
| 交通費（出張レッスン・研修） | 経費になりうる | 私用と兼ねた移動は分ける |
| 衣装・ドレス | 要相談 | 普段にも着られる服は判断が分かれやすい |
| 防音工事 | 要相談 | 内容と金額で、その年の経費か数年に分けるかが変わる |
| 所得税・住民税 | ならない | 国税庁の案内で明記 |
| 同居の家族に払う家賃 | ならない | 生計を一にする親族への家賃は必要経費にならない |

全29項目と「残しておく記録」の列は、印刷用の一覧表にまとめました。

## 楽譜・教材・調律の考え方

楽譜や教本は、指導に使う物なら経費として扱われる可能性が高い項目です。ただ、ピアノ講師は自分の趣味でも楽譜を買うことが多く、私用との線引きがあいまいになりがちです。**買ったときに、どの生徒・どの指導に使うかをレシートにメモしておく**と、あとで説明しやすくなります。

調律と修理は、教室で使うピアノの分が対象です。自宅のピアノを家族も弾いている場合は、家事関連費の考え方で、仕事の部分を分けることになります。分け方に決まった式はないので、レッスンで使う時間の記録などを残しておきます。

メトロノーム、譜面台、椅子のような道具は、取得価額が10万円未満なら、使い始めた年に全額を必要経費にします（[No.2100 減価償却のあらまし](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2100.htm)、2026年11月11日確認）。

## ピアノ本体は金額で扱いが変わる

ピアノのように長く使う物は、買った年に全額を経費にせず、使える期間に分けて経費にします。これを減価償却といいます。国税庁の[No.2100](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2100.htm)では、金額によって次のように扱いが分かれます（2026年11月11日確認）。

| 取得価額 | 扱い |
|---|---|
| 10万円未満 | 使い始めた年に全額を必要経費にする |
| 10万円以上20万円未満 | 一括償却資産として、3年で3分の1ずつ必要経費にする方法を選べる |
| 10万円以上40万円未満（一定の要件を満たす青色申告者のみ） | 令和8年4月1日以後に取得した物は、年の合計300万円までを、取得した年に全額必要経費にできる特例がある（令和11年3月31日までの取得分が対象）。令和8年3月31日までに取得した物は30万円未満が対象。一括償却を選ぶ物は除く |
| 上のどれにも当てはまらない | 耐用年数にわたって減価償却する |

金額の判定は、消費税の経理方式で税込か税抜かが決まります。消費税の免税事業者は税込の金額で判定します（同じページの説明による）。

### 耐用年数は5年、償却率は0.200

ピアノの耐用年数は、「減価償却資産の耐用年数等に関する省令」の別表第一で、器具及び備品の「前掲のもの以外のもの」にある**楽器が5年**です。定額法の償却率は、同じ省令の別表第八で、耐用年数5年が**0.200**です（[e-Gov法令検索](https://laws.e-gov.go.jp/law/340M50000040015)、2026年11月11日確認）。

定額法の計算は「取得価額 × 償却率」で、年の途中から使い始めたときは、12で割って使った月数を掛けます（[No.2106 定額法と定率法による減価償却](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2106.htm)、同日確認）。

**計算例**（架空の例。教室専用のピアノとします）

- 1,500,000円のピアノを買い、2026年4月から教室で使い始めた
- 1年分の償却費：1,500,000円 × 0.200 ＝ 300,000円
- 2026年分：300,000円 × 9か月 ÷ 12 ＝ 225,000円
- 2027年〜2030年分：毎年300,000円
- 2031年分：残りから1円を引いた74,999円（最後の年は帳簿上の残りが1円になるまで）

家族も弾くピアノの場合は、ここで出した償却費のうち、仕事に使った部分だけを経費にすることになります。

### 中古のピアノ・前から持っていたピアノ

**中古のピアノを買った場合**は、使える期間を見積もって耐用年数にします。見積もりが難しいときの簡便法は、法定の耐用年数をすべて過ぎた物なら「法定の年数 × 20%」、1年未満は切り捨て、2年未満なら2年です（[No.2108](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2108.htm)、2026年11月11日確認）。たとえば（例）、法定耐用年数の5年をすべて過ぎた、製造から8年たったピアノなら、5年 × 20% ＝ 1年で、2年未満なので耐用年数は2年です。

**もともと家で弾いていたピアノを教室用にした場合**は、買ってから教室に使うまでの期間について、耐用年数の1.5倍の年数で価値の減り方を計算し、残りの価額から償却を始めます（同じページ）。買った年と値段の記録があると計算できます。計算が複雑なので、税務署に確認しながら進めると安心です。

## 自宅教室の家賃・光熱費の按分

自宅をレッスン室にしている場合、家賃や電気・ガス・水道は私用と仕事が混ざる家事関連費です。国税庁の[No.2210](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2210.htm)では、仕事に直接必要だった部分を**明らかに区分できる金額だけ**が必要経費になります（2026年11月11日確認）。割合の決め方の式は示されていないので、面積や使う時間など、説明できる根拠で分けます。

**計算例**（架空の例）

- 家賃 月120,000円、住まい全体60㎡のうち、レッスン室が15㎡
- 面積の割合：15㎡ ÷ 60㎡ ＝ 25%
- 1か月分：120,000円 × 25% ＝ 30,000円
- 1年分：30,000円 × 12か月 ＝ 360,000円

レッスン室を夜は家族の部屋として使うなど、時間で使い方が変わる場合は、時間の割合も考えることがあります。間取り図とレッスンの時間割を残しておくと、割合の根拠を説明しやすくなります。

持ち家の場合、固定資産税は業務用の部分だけが必要経費になります。一方、**同じ家計で暮らす家族（生計を一にする親族）に払う家賃は必要経費になりません**（同じページ）。親の家で教えていて家賃を渡している、という場合は注意が必要です。

## 研修・発表会・交通費・衣装

- **研修・講座・セミナー**：指導法の講座や研究会の参加費は、指導の仕事とのつながりを説明できれば経費として扱われる可能性があります。一方、自分が先生に習うレッスン代は、指導に直結するか趣味の習い事かで判断が分かれやすい項目です。
- **発表会**：会場費、調律、プログラムの印刷、記念品などは経費の側です。生徒から参加費を集めたときは、その参加費を収入として記録します。経費だけ載せて参加費を載せない、という形にならないよう、参加費の一覧を残します。
- **交通費**：出張レッスンや研修への移動は経費の側です。買い物や私用と兼ねた移動は、仕事の部分を分けます。日付・行き先・金額をメモしておきます。
- **衣装・ドレス**：発表会や演奏で着る服でも、普段にも着られる物は判断が分かれやすい項目です。着た場面を記録しておき、迷ったら相談してください。

## 経費にならないもの

国税庁の[No.2210](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2210.htm)に明記されているものを挙げます（2026年11月11日確認）。

- 所得税と住民税（個人事業税は全額が必要経費）
- 生計を一にする親族に払う家賃
- 生計を一にする親族に払う給与（青色事業専従者給与は除く。青色申告でない人は事業専従者控除の金額が必要経費とみなされる）

## 1年分の記録を楽にする

経費の一覧があっても、領収書がそろっていなければ使えません。白色申告の人も帳簿を付ける必要があり、収入と経費を書いた帳簿は7年、領収書などの書類は5年保存します。日々の合計をまとめて書く簡易な記帳も認められています（[No.2080](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2080.htm)、2026年11月11日確認）。

- 領収書は月ごとに封筒かフォルダにまとめ、余白に「どの指導に使ったか」を書く
- ピアノなど高い物は、買った日・使い始めた月・値段を1枚にまとめておく
- 按分する費用は、割合の根拠（間取り・時間割）を年に1回メモしておく

収入の側は、月謝を受け取った日と金額の記録が土台です。手渡しの月謝なら、[月謝袋のテンプレート](/guide/gessha-bukuro-template/)で受け取りの印を残す方法があります。表で管理するなら[月謝管理表のエクセルテンプレート](/guide/gessha-kanrihyo-excel/)が使えます。

ここからは自社アプリの紹介です。motytools（このサイトの運営者）が作っているiPhoneアプリ「[レッスン手帳](/apps/lesson-techo/)」は、生徒ごとの月謝の入金と未納を月ごとに記録できます。Premium（月額480円、年額4,600円）では、月謝台帳をCSVで書き出せるので、収入の集計の材料になります。**経費を記録する機能はありません**。確定申告の書類を作る機能もないので、経費は紙やこの記事の一覧表で管理してください。無料で使えるのは生徒5人までです。

## 迷ったときの相談先

一覧で「要相談」にした項目や、按分の割合に迷ったときは、早めに聞くのが確実です。

- **税務署の電話相談**：所轄の税務署に電話し、自動音声で「1」を選ぶと電話相談センターにつながります。受付は平日8時30分〜17時です（[国税庁 税に関するご相談について](https://www.nta.go.jp/taxes/shiraberu/sodan/denwa-sodan/index.htm)、2026年11月11日確認）。
- **税理士**：ピアノの購入や防音工事のように金額が大きい支出は、買う前・工事の前に相談すると、どの制度が使えるかを先に確かめられます。

教室の運営では、月謝そのものの決め方も確定申告の数字に直結します。相場は[ピアノ教室の月謝の相場](/guide/piano-gessha-souba/)、払われていない月謝の請求期間は[月謝の未払いの時効](/guide/gessha-mibarai-jikou/)にまとめています。
