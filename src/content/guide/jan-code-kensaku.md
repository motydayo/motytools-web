商品のバーコードから商品名や価格を調べるには、バーコードの下に印刷された13桁の数字を、通販サイトや検索窓にそのまま入れるのが基本です。数字を打つのが面倒なときは、カメラで読み取るアプリが使えます。この記事では、番号の意味、探し方、そして「検索しても出てこない」ときの理由を整理します。

## JANコードとは

スーパーや家電量販店で見かけるバーコードの多くは、JANコードです。国際的にはGTINと呼ばれる商品識別の仕組みで、運営しているのは流通システム開発センター（GS1 Japan）です。[GS1 Japanの説明](https://www.gs1jp.org/code/jan/about_jan.html)では、「どの事業者の、どの商品か」を表す番号とされています。

桁数は2種類です（2026年10月12日に確認）。

- 標準タイプ：13桁
- 短縮タイプ：8桁（小さな商品に付ける）

13桁の標準タイプは、3つの部分でできています。

1. GS1事業者コード（メーカーなどに貸し出される番号。7桁、9桁、10桁のいずれか）
2. 商品アイテムコード（事業者が商品ごとに決める番号。事業者コードの桁数に応じて5桁、3桁、2桁）
3. チェックデジット（読み間違いを見つけるための検算用の1桁）

GS1 Japanが貸し出す事業者コードは「45」か「49」で始まります。そのため、日本のメーカーの商品は、45か49で始まる13桁が多くなります。

JANコードは商品を見分けるための番号で、価格や賞味期限は入っていません。価格は、お店や通販サイトが番号に結びつけて管理しています。賞味期限とバーコードの関係は、[賞味期限はバーコードでわかるのか](/guide/shomikigen-barcode/)で説明しています。

## 番号で検索する方法

### 検索窓に13桁を入れる

最も手軽なのは、番号を検索窓に入れる方法です。

1. 商品のバーコードの下にある数字を確認する（13桁、または8桁）
2. 検索サイトや、楽天市場・Yahoo!ショッピングの検索窓に、数字だけを入れる
3. 検索結果から、商品名やパッケージが同じ物を選ぶ

入れ方の注意は3つあります。

- **スペースやハイフンを入れない**：バーコードの下の数字は、4桁ずつ離れて印刷されていることがあります。続けて入力してください
- **半角で入れる**：数字は半角にそろえます
- **先頭の0を消さない**：0で始まる番号は、0も含めた桁数で入れます

Yahoo!ショッピングで同じ商品が見つかったあと、いちばん安い店を探す手順は[Yahoo!ショッピングで最安値を探す方法](/guide/yahoo-saiyasune-hyouji/)に書きました。

Amazonの商品ページは、Amazon独自の管理番号（ASIN）で整理されていて、JANコードとは別物です。AmazonでJANコードを検索窓に入れても、同じ商品が出るとは限りません。

手入力のミスを見つけたいときは、チェックデジットで検算できます。13桁の場合、左の12桁について、右端から順に「3、1、3、1…」を掛けて合計し、その合計に足すと10の倍数になる数が、13桁目です。説明用の架空の番号「450123456789」で確かめます。

- 右から順に掛ける：9×3、8×1、7×3、6×1、5×3、4×1、3×3、2×1、1×3、0×1、5×3、4×1
- 合計：27＋8＋21＋6＋15＋4＋9＋2＋3＋0＋15＋4＝114
- 114に何を足すと10の倍数（120）になるか：6

したがって13桁目は6で、この例の番号は「4501234567896」です（説明用の番号で、実在する商品とは限りません）。打ち込んだ番号の13桁目が計算と合わなければ、どこかを打ち間違えています。

### 本のバーコードは上段

本の裏表紙には、バーコードが上下2段で付いています（書籍JANコード）。[GS1 Japanの説明](https://www.gs1jp.org/code/jan_publication/)では、次のとおりです。

- 上段：「978」で始まる、国際標準の書籍の番号（ISBN）
- 下段：日本独自の図書分類と、税抜きの本体価格

本を探すときは、**上段の13桁**を使います。下段は本の識別ではなく分類と価格を表す番号なので、通販サイトで検索しても本は出ません。

## カメラで読んで検索する方法

売り場で本を何冊も、日用品を何個も調べるときは、数字を打つより読み取るほうが速いです。ここからは自社アプリの紹介です。当サイトを運営するmotytoolsが作っているiPhoneアプリ「[ピッと最安](/price-scan/)」を例に、手順を説明します。

1. アプリを開く。初回はカメラの許可を求められるので「許可」を選ぶ（会員登録は要りません）
2. 画面の枠にバーコードを合わせる。暗い売り場では、フラッシュのボタンを押す
3. 読み取ると、結果画面に楽天市場とYahoo!ショッピングの最安値が大きく出る。タップで商品ページへ移動できる
4. 読めないときは、画面の「番号を手で入力」から数字を入れる

カメラの映像は保存も送信もされず、通販サイトに送られるのはバーコードの番号だけです。読み取った商品は、サムネイルと最安値つきで、端末の中の履歴に残ります。

できないこともあります。Amazonと価格.comは価格を表示せず、検索結果を開くボタンで移動する形です。Android版はなく、iPhone（iOS 15.1以降）だけです。料金は無料（広告あり）で、広告を消すのは買い切りです。

## 検索しても出てこない理由

番号を入れても商品が出ないときは、次のどれかが多いです。当てはまる物から順に確かめてください。

| 理由 | 見分け方 | 対処 |
|---|---|---|
| 入力ミス・読み違い | 13桁目が検算と合わない | 数字を打ち直す。アプリなら読み取り直す |
| 本の下段を読んだ | 本のバーコードが2段あり、下段を読んでいる | 上段（978で始まる13桁）を使う |
| 店が貼ったシールの番号 | 先頭が20〜29で始まる。値段が入った後付けのシール | 箱や袋に印刷されたバーコードを探す。無ければ商品名で探す |
| 8桁の短縮コード | 8桁の番号 | 通販では13桁で登録されることが多い。商品名や品番で探す |
| 番号が変わった | パッケージが新しくなった、中身を変更した商品 | 新しい番号で登録し直されていることがある。商品名で探す |
| 海外の商品 | 45・49以外で始まる | 日本の通販に同じ番号で載っていないことがある。商品名で探す |
| 通販に出回らない商品 | パン、惣菜、野菜、肉、その日限りの日配品 | 店頭で買うのが現実的 |

### 店舗独自のコード

GS1 Japanの[食品軽包装業界のガイド](https://www.gs1jp.org/standard/industry/food-package/food-packageguide.pdf)では、先頭が20〜29のコードは、お店が社内の管理や会計のために設定する「インストアマーキング用」のコードとされています。値段が入ったラベルが後から貼ってある、量り売りの惣菜やパンがこれにあたります。お店の中だけで使う番号なので、通販サイトでは検索できません。

### リニューアルと海外品

GS1 Japanによると、中身やパッケージの変更の内容によっては、商品の番号を新しく付け直す決まりがあります。リニューアルした商品は、通販サイトの登録が新しい番号に切り替わっていることがあり、古い箱の番号では見つからない場合があります。

海外から輸入された商品は、日本の事業者コード（45・49）ではない番号で作られています。並行輸入の商品は、日本の通販サイトに同じ番号で載っていない場合があります。

### 8桁のコード

短縮タイプの8桁は、13桁に直す方法が決まっていません。ピッと最安の開発時に、Yahoo!ショッピングの商品データ5カテゴリ124件を調べたところ、番号は全件13桁で、8桁の商品はありませんでした。8桁のバーコードは、通販サイトでは番号から商品を探しにくいと考えてください。

番号で見つからないときは、パッケージのメーカー名と商品名、品番を検索窓に入れます。そのうえで、箱の容量や内容量が同じ商品かを必ず確かめてください。名前だけで探すと、似た別の商品を見てしまうことがあります。

## ここまでのまとめ

- 標準のJANコードは13桁。日本のメーカーの商品は45か49で始まる
- 検索窓には数字だけを半角で入れる。本は上段を使う
- 売り場ではカメラで読むほうが速い。店頭とネットで値段が違うわけは[ネットと店頭の価格が違う理由](/guide/net-tento-kakaku/)を参照
- 出てこないのは、入力ミス、店のシール、8桁、リニューアル、通販に無い商品のどれかが多い
