材料からレシピを探すとき、食材を入れるほど結果が減り、最後は0件になることがあります。この記事では、クックパッドのウェブ版で実際に数えた件数を使い、複数の食材で探すコツと、結果が出ないときの直し方を説明します。後半では、検索とは逆に「食材を足すほど増える」探し方も紹介します。

## 材料から探すときの基本

### 主役の食材を1つ決める

最初に入れるのは、「今日使い切りたい食材」1つです。肉や魚など、料理の中心になる物が向いています。

試しに、2026年10月12日にクックパッドのウェブ版で「鶏もも」だけを検索すると、112,186件が表示されました。ここから、脇役の食材を足して絞り込んでいきます。

### 2つ目までにとどめる

検索は、入れた語をすべて含むレシピだけを出します（「AND検索」といいます）。語を増やすほど、条件に合うレシピが減ります。次の表は、同じ日に同じ食材を1つずつ足した結果です。

| 検索語（スペースで区切って入力） | 表示された件数 |
|---|---|
| 鶏もも | 112,186件 |
| 鶏もも キャベツ | 5,555件 |
| 鶏もも キャベツ 卵 | 627件 |
| 鶏もも キャベツ 卵 ピーマン | 43件 |
| 鶏もも キャベツ 卵 ちくわ | 17件 |
| 鶏もも キャベツ 卵 ピーマン ちくわ | 2件 |

食材が1つ増えるごとに、結果は桁が変わるほど減ります。5つ入れた時点で、2件まで減りました。この件数は、サイトの更新で日々変わります。注目してほしいのは件数そのものではなく、**減り方**です。

3つまでは、まだ数百件が残ります。4つ以上にすると、上位に出るレシピも、探している物とずれやすくなります。主役1つ、脇役1〜2つを目安にします。

## レシピサイトでの検索のコツ

### スペースで区切る

複数の食材は、半角か全角のスペースで区切って入れます。「鶏もも キャベツ」のように入れると、両方を含むレシピが出ます。クックパッドのウェブ版で、検索結果が見つからなかった場合に出る案内にも、単語の間にスペースを入れる方法が書かれていました。

### 除外したい食材

使いたくない食材（苦手な物、切らした物）は、語の前に「-」（マイナス）を付けて除外できます。クックパッドのウェブ版で「鶏もも キャベツ -卵」と入れると、5,555件だった結果が4,918件になり、上位の5件のタイトルに「卵」は含まれていませんでした。

ただし、この除外の書き方は、検索ページに説明が出る機能ではありません。サイトの仕様変更で使えなくなることも考えられるので、うまくいかなければ、検索結果の絞り込み機能で試してください。

### 調味料は検索語に入れない

「しょうゆ」「みりん」のような調味料は、検索語に入れない方が結果が多く出ます。

同じ日に「鶏もも キャベツ しょうゆ」で検索すると2,425件で、「鶏もも キャベツ」の5,555件の半分以下でした。調味料は家に常備している前提の料理が大半なので、検索語に入れても、探している食材の組み合わせに近づきません。入れた分だけ候補が減り、むしろ損です。

なお、「醤油」と入れても件数は2,425件で同じでした。クックパッドでは、「人参」と「にんじん」を検索しても、どちらも470,052件と同じ件数でした。表記ゆれをサイト側でまとめている様子です。ほかのサイトでも同じとは限らないので、結果が少ないときは別の書き方も試してください。

## 検索結果が少ない・0件になるとき

結果が少ない、または出ないときは、次の順で直します。

1. **食材を1つ減らす**: いちばん影響が大きい方法です。最後に足した脇役から外します
2. **調味料を外す**: 入れていたら、真っ先に外します
3. **一般的な名前にする**: 「鶏もも肉」を「鶏肉」、「豚こま切れ」を「豚肉」にするなど、範囲の広い名前にします
4. **表記を変える**: ひらがな、漢字、カタカナを変えて試します。サイト側でまとめられている場合は変わりませんが、まとめられていないサイトでは件数が変わります
5. **結果を広めに見て、置き換える**: 食材2つで出た結果の中から、残りの食材を材料表の似た物と置き換えられるレシピを探します。全部の語を含むレシピにこだわらないことが、0件を避ける近道です

食材を減らして見つかったレシピは、手元の残りの食材で足りない分を置き換えれば、そのまま使えることが多いです。役割での置き換え方は、[あるもので料理するコツ](/guide/arumono-ryori-kotsu/)にまとめています。

## 持っている食材を全部まとめて探す方法

検索には、構造上の限界があります。**食材を足すほど結果が減る**ので、冷蔵庫の中身を全部入れて探すことができません。

そこで、逆の性質を持つ探し方があります。持っている食材を先に登録して、そこから作れる料理を出す方法です。このタイプは、**食材を足すほど作れる料理が増えます**。

ここからは自社アプリの紹介です。motytools（このサイトの運営者）が作っているiPhoneアプリ[あるものレシピ](/arumono-recipe/)は、食材をタップで選ぶと、その食材でそろう料理が一覧で並びます。

[[app]]

先ほどと同じ食材で、アプリの収録データ（家庭料理477品）を使って数えた結果が次の表です。しょうゆやみりんなど21品の調味料は、最初から「ある」扱いにして数えています。

| 選んだ食材 | 今すぐ作れる料理 |
|---|---|
| 鶏もも肉 | 6品 |
| 鶏もも肉、キャベツ | 9品 |
| 鶏もも肉、キャベツ、卵 | 18品 |
| 鶏もも肉、キャベツ、卵、ピーマン、ちくわ | 21品 |

検索では5つ入れると2件まで減った食材の組み合わせが、アプリでは食材を足すごとに増えて、21品になりました。さらに、材料が1つだけ足りない「あと1つ」の料理も、別に並びます。

このアプリの限界も書いておきます。収録は477品なので、検索サイトのような膨大な数の中から探すことはできません。出るのは、収録している家庭料理の範囲だけです。通信がなくても動き、会員登録も不要です。外部のレシピを見たいときは、同じ料理名でクックパッド、クラシル、YouTube、楽天レシピの検索結果を開くボタンがあります。

使い分けの目安は、次のとおりです。

- 食べたい料理がはっきりしている、または食材を1〜2つに絞れる: 検索サイト
- 冷蔵庫の中身を全部生かして、考えずに候補を出したい: 登録型のアプリ

アプリの種類ごとの違いは、[冷蔵庫の余り物でレシピがわかるアプリ比較](/guide/reizoko-amarimono-app/)に表でまとめました。AIに食材を伝えて考えてもらう方法は、[冷蔵庫にあるものでAIにレシピを聞く方法](/guide/reizoko-recipe-ai/)で、注意点と一緒に説明しています。
