レシピをエクセルで管理したい人向けに、**材料名で探せるレシピ管理表**の作り方をまとめました。そのまま使える無料テンプレート（xlsx）も配っています。Googleスプレッドシートに取り込んでも同じ式で動きます。

## 無料テンプレートの中身

[レシピ管理表テンプレート（recipe-kanri-hyou.xlsx・約18KB）](/guide/recipe-kanri-excel/recipe-kanri-hyou.xlsx)をダウンロードして使えます。見本として架空のレシピを12品入れてあるので、消してから自分のレシピを入れてください。

| シート | できること |
|---|---|
| レシピ一覧 | 1行に1品ずつ記録する。見出しの▼で分類・時間・評価ごとに絞り込める。100行まで |
| さがす | 黄色のマスに「キャベツ」などと入れると、料理名か主な材料にその言葉を含むレシピが一覧で出る。言葉を2つ入れると、両方を含むものだけ出る |
| 使い方 | 入れ方の決まりと、FILTER関数を使う場合の式 |

「さがす」で探した言葉に合う行は、「レシピ一覧」でも薄い緑色になります。分類は入力欄から選ぶ形にしてあります。時間と評価は、決めた範囲の数字以外を入れると注意が出ます。

## レシピ管理表に入れる列と書き方

列を増やしすぎると、入れるのが面倒になって続きません。テンプレートでは次の9列にしました。

| 列 | 書き方の例 | 入れる理由 |
|---|---|---|
| 料理名 | 鶏むね肉のねぎ塩レンジ蒸し | 探すときの一番の手がかり |
| 分類 | 主菜／副菜／汁物／ご飯・麺／作り置き／お菓子 | 「副菜だけ見たい」ときに絞る |
| 主な材料 | 鶏むね肉、長ねぎ、ごま油 | 冷蔵庫の残り物から探す |
| 時間（分） | 15 | 「15分以内」で絞る |
| 出どころ | インスタ／料理本／家族から | どこで見たか思い出せる |
| URL | 元のページのアドレス | 作るときに手順を見に行く |
| 作った日 | 2026/10/3 | 最近作っていない物を探す |
| 評価（1〜5） | 4 | また作りたい物だけ見る |
| メモ | 味が薄め。しょうゆ足す | 次に作るときの直し |

書き方で効いてくるのは、**主な材料**の欄です。

- 探すときに思い浮かべる材料を3つ前後だけ書く。塩・しょうゆなどの調味料は書かない（入れると、どの言葉で探してもほとんどのレシピが出てしまう）
- 表記をそろえる。「玉ねぎ」「たまねぎ」「タマネギ」は別の文字なので、どれか1つに決める
- 区切りは読点（、）に統一する

出どころがインスタの投稿なら、URL欄に投稿のアドレスを貼っておくと、あとで開き直せます。投稿のアドレスは、投稿の共有メニューから「リンクをコピー」で取れます（アプリの版によって表示が違う場合があります）。インスタで保存した投稿を見返しやすくする方法は、[インスタのレシピを保存する方法4つ](/guide/instagram-recipe-hozon/)で比べています。

## 材料名で探す仕組み（式の中身）

テンプレートの「さがす」シートは、2つの式を組み合わせて動いています。自分で表を作る場合も、同じ考え方で作れます。

### 1. 一覧の各行に「何件目に合ったか」の番号を振る

「レシピ一覧」のいちばん右の「一致」の列に、次の式が入っています（6行目の例。B3が探す言葉①）。

```
=IF(A6="","",IF(ISNUMBER(SEARCH('さがす'!$B$3,A6&" "&C6)),MAX(J$5:J5)+1,""))
```

- `A6&" "&C6` で、料理名と主な材料を1つの文字列にまとめる
- `SEARCH` は、探す言葉がその中に含まれていれば位置の数字を返し、無ければエラーを返す。`ISNUMBER` で「含む／含まない」に変える
- 含む行には、自分より上の行の番号の最大値＋1を入れる。上から順に1、2、3…と振られる

配布版は、言葉を2つ入れられるようにしたり、言葉が空のときは何も出さないようにしたりしているため、これより少し長い式です。

### 2. 「さがす」シートで、番号の1番から順に引き出す

「さがす」シートの結果欄には、次の形の式が入っています（料理名の列の例）。

```
=IFERROR(INDEX('レシピ一覧'!$A$6:$A$105,MATCH(ROW()-ROW($A$6),'レシピ一覧'!$J$6:$J$105,0)),"")
```

`ROW()-ROW($A$6)` は「結果欄の何行目か」で、1行目なら1になります。`MATCH` で一致の番号が1の行を探し、`INDEX` でその行の料理名を取り出します。番号が見つからない行は `IFERROR` で空欄にします。

FILTER関数（条件に合う行だけを抜き出す関数）を使えば1つの式で済みますが、使えるExcelの版が限られます。そのため配布版は、どの版でも使える上の組み合わせにしました。8通りの言葉（「キャベツ」「鶏」と「卵」の2語、該当なしなど）で探して、出てくる件数と行が正しいことを確かめています。

### FILTER関数で1つの式にする場合

Microsoftのサポートページでは、FILTER関数の対象としてMicrosoft 365、Excel 2024、Excel 2021、iPhone・iPad版とAndroid版のExcelが挙がっています（[FILTER関数（Microsoft サポート）](https://support.microsoft.com/ja-jp/office/filter-%E9%96%A2%E6%95%B0-f4f7cb66-82eb-4767-8f7c-4877ad80c759)、2026年11月11日確認）。Excel 2019より前の版には一覧にありません。

使える版なら、空いたシートのB3に探す言葉を入れて、A6に次の式を入れます。結果は下と右に広がって表示されます。

```
=IFERROR(FILTER('レシピ一覧'!A6:I105,('レシピ一覧'!A6:A105<>"")*ISNUMBER(SEARCH(B3,'レシピ一覧'!A6:A105&" "&'レシピ一覧'!C6:C105))),"見つかりません")
```

Excelでは、条件を2つ以上かけるときは条件同士を `*` でつなぎます。GoogleスプレッドシートのFILTER関数は、条件をカンマで区切って並べる書き方です（[FILTER関数（Google ドキュメント エディタ ヘルプ）](https://support.google.com/docs/answer/3093197?hl=ja)、2026年11月11日確認）。スプレッドシートでは次のように書きます。

```
=IFERROR(FILTER('レシピ一覧'!A6:I105,'レシピ一覧'!A6:A105<>"",ISNUMBER(SEARCH(B3,'レシピ一覧'!A6:A105&" "&'レシピ一覧'!C6:C105))),"見つかりません")
```

GoogleスプレッドシートのFILTER関数は、合う行が無いとエラー（#N/A）を返すとヘルプにあります。上の式は `IFERROR` で囲んで「見つかりません」と出るようにしています。

## フィルターで分類・時間・評価を絞り込む

探す言葉が決まっていないときは、表のフィルター機能のほうが手早く使えます。テンプレートの「レシピ一覧」はテーブル（Excelの、見出しに▼が付く表の形式）にしてあるので、最初から見出しに▼があります。

自分で作った表にフィルターを付ける場合は、Excelなら表の中のセルを選んで「データ」→「フィルター」です。表全体をテーブルにする場合は「挿入」→「テーブル」か、「ホーム」→「テーブルとして書式設定」を使います（[Microsoft サポート：フィルター](https://support.microsoft.com/ja-jp/office/%E7%AF%84%E5%9B%B2%E5%86%85%E3%81%BE%E3%81%9F%E3%81%AF%E3%83%86%E3%83%BC%E3%83%96%E3%83%AB%E5%86%85%E3%81%AE%E3%83%87%E3%83%BC%E3%82%BF%E3%81%AB%E3%83%95%E3%82%A3%E3%83%AB%E3%82%BF%E3%83%BC%E3%82%92%E9%81%A9%E7%94%A8%E3%81%99%E3%82%8B-01832226-31b5-4568-8806-38c37dcc180e)・[テーブルの作成](https://support.microsoft.com/ja-jp/office/%E8%A1%A8%E3%82%92%E4%BD%9C%E6%88%90%E3%81%8A%E3%82%88%E3%81%B3%E6%9B%B8%E5%BC%8F%E8%A8%AD%E5%AE%9A%E3%81%99%E3%82%8B-e81aa349-b006-4f8a-9806-5af9df0ac664)、2026年11月11日確認）。

よく使う絞り込みの例です。

1. 「分類」の▼で「副菜」だけにチェックを入れる → 副菜だけが残る
2. 「時間（分）」の▼で数値フィルターの「指定の値以下」を選び、15を入れる → 15分以内で作れる物だけになる
3. 「評価」の▼で4と5だけにチェックを入れる → また作りたい物だけになる
4. 「作った日」の▼で並べ替えを「古い順」にする → しばらく作っていない物が上に来る

▼のメニューの名前は、ExcelのWindows版とMac版、版の違いで表示が変わることがあります。

Googleスプレッドシートでは、範囲を選んで「データ」→「フィルタを作成」です。見出しのフィルタのアイコンから「条件でフィルタ」を選ぶと、条件を指定して絞れます（[データの並べ替えとフィルタ（Google ドキュメント エディタ ヘルプ）](https://support.google.com/docs/answer/3540681?hl=ja)、2026年11月11日確認）。

## Googleスプレッドシートで使う

スマホやほかの家族と同じ表を見たいなら、Googleスプレッドシートに移す方法があります。やり方は2つです。

1. Googleドライブにxlsxファイルをアップロードし、ダブルクリックで開く。Googleのヘルプでは、Officeファイルをダブルクリックでスプレッドシートなどで開けると案内されています。Office形式のまま開く設定になっている場合は、下の2を使ってください（[Office ファイルの使用（Google ドキュメント エディタ ヘルプ）](https://support.google.com/docs/answer/6055139?hl=ja)）
2. Googleスプレッドシートを開いて「ファイル」→「インポート」でファイルを選び、「新しいスプレッドシートを作成する」などを選んで「インポート」を押す（[データセットとスプレッドシートを読み込む（同ヘルプ）](https://support.google.com/docs/answer/40608?hl=ja)）

どちらも2026年11月11日にGoogleのヘルプで確認しました。テンプレートの式は、ExcelとGoogleスプレッドシートの両方にある関数（IF・AND・OR・SEARCH・ISNUMBER・MAX・COUNT・INDEX・MATCH・ROW・IFERROR）だけで作っています。表の色や罫線、テーブルの見た目は取り込み後に変わる場合があります。

## 表で続けるコツと、手間がかかるところ

続けるには、**作った日と評価だけは必ず入れる**と決めるのが楽です。この2列が埋まっていれば、「最近作っていない」「家族に好評だった」物をすぐ選べます。逆に、手順まで書き写そうとすると1品ごとに時間がかかり、続きません。手順はURLの先に任せて、表には探すための情報だけを置きます。

表で管理するときに手間がかかるのは、次の2つです。

- インスタやTikTokで見つけるたびに、パソコンかスマホで表を開いて料理名・材料・URLを入力する
- 元の投稿が消されたり非公開になったりすると、URLから手順を見られなくなる

インスタの保存コレクションと表を併用する人は、コレクションの中の順番も気になるところです。どこまで並べ替えられるかは[インスタの保存コレクションの並び替え・順番の変え方](/guide/instagram-collection-narabikae/)で説明しています。

ここからは自社アプリの紹介です。motytools（このサイトの運営者）が作っているiPhoneアプリ「[レシピスクラップ](/recipescrap/)」は、インスタやTikTok、レシピサイトの共有ボタンからレシピを取り込み、材料と手順だけの形で端末に保存します。料理名でも材料名でも検索できるので、表の「主な材料」欄を手で入れる作業がいりません。できないことも書いておきます。iPhone専用でAndroidとパソコンでは使えません。レシピは端末の中だけに保存されるので、スプレッドシートのように家族と同じ表を見る使い方には向きません。取り込みは無料で月10件までで、月150件まで使えるプレミアムは月額800円です。ほかのレシピ保存サービスの保存件数の上限については、[クラシルの保存上限は無料30件？](/guide/recipe-hozon-jougen/)で確認日つきでまとめています。

表とアプリは、どちらか一方に決める必要はありません。家族で献立を相談するならスプレッドシート、台所で手順を見ながら作るならアプリ、と使い分けることもできます。
