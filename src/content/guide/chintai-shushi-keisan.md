賃貸物件の収支は、「家賃から出費を引いた残り」を計算するだけですが、何を引くかで結果が大きく変わります。この記事では、区分マンション1室の例（すべて架空の数字）で、毎年の手残り（キャッシュフロー）を出す手順を示します。あわせて、帳簿上の所得と手元に残るお金がずれる理由も、1つの表で説明します。税金は含めず、税引き前の計算です。

## 収支計算に使う数字

収入と支出を、年額でそろえて書き出します。

**収入側**

- 家賃と共益費（満室の年額）
- 空室や滞納による減り
- 礼金、更新料などの一時的な収入

**支出側**

- 管理費（区分マンションの場合は建物の管理組合に払う費用）。修繕積立金が別にかかる場合は、自分の数字に加えてください
- 管理会社への手数料
- 固定資産税・都市計画税
- 火災保険料
- 修繕費や設備の交換費
- ローンの返済額（元本と利子の合計）

国税庁の冊子では、借入金の返済額のうち元本にあたる部分は必要経費にならないとされています。ただし、お金は出ていくので、手残りを出すときは、元本の返済も引きます。

## 計算例：区分マンション1室

次は、すべて架空の例です。

- 物件価格 1,500万円、頭金 300万円、借入 1,200万円
- ローンは年利1.5%、25年、元利均等返済
- 家賃 月80,000円
- 管理費 月8,000円、管理会社への手数料は実際の家賃収入の5%
- 固定資産税・都市計画税 年70,000円、火災保険料 年12,000円
- 空室は1年のうち1か月と見込む

ローンの返済額は、サイト内の[住宅ローンシミュレーター](/loan/)で、借入額1,200万円、年利1.5%、返済期間25年、元利均等を入れて確かめられます。毎月の返済額は約47,992円で、年額は47,992円 × 12 = 575,904円です。最初の1年に払う利子は約177,267円、元本は約398,637円になります。

| 項目 | 年額（円） |
|---|---|
| 家賃（満室の年額） 80,000円 × 12か月 | 960,000 |
| 空室1か月分 | −80,000 |
| 実際の家賃収入 | 880,000 |
| 管理費 8,000円 × 12か月 | −96,000 |
| 管理会社の手数料 880,000円 × 5% | −44,000 |
| 固定資産税・都市計画税 | −70,000 |
| 火災保険料 | −12,000 |
| ローン返済（元本と利子の合計） | −575,904 |
| 手残り（税引き前のキャッシュフロー） | 82,096 |

880,000 − 96,000 − 44,000 − 70,000 − 12,000 − 575,904 = 82,096円です。月あたりに直すと約6,841円になります。表面利回りは、満室の年額 960,000円 ÷ 物件価格 15,000,000円 = 6.4%です。

## 空室と修繕を見込む

同じ物件でも、空室の長さと修繕の有無で、手残りは変わります。同じ条件で、空室と修繕費（年60,000円と仮定）を変えた例です。管理会社の手数料は、実際の家賃収入の5%で計算しなおしています。

| ケース | 実際の家賃収入 | 修繕費 | 手残り（円） |
|---|---|---|---|
| 満室（空室なし） | 960,000 | 0 | 158,096 |
| 空室1か月 | 880,000 | 0 | 82,096 |
| 空室1か月と修繕費 | 880,000 | 60,000 | 22,096 |
| 空室2か月と修繕費 | 800,000 | 60,000 | −53,904 |

最後の行は、帳簿の計算では黒字になっても、手元のお金は赤字になる例です。借入のある物件では、家賃収入が少し減るだけで、手残りがマイナスになる場合があります。将来の計画では、満室の数字ではなく、空室と修繕を見込んだ数字で見てください。空室は物件や地域で違うので、近隣の状況は管理会社や不動産会社に聞いてください。

## キャッシュフローと所得の違い

確定申告で使う不動産所得は、収入から必要経費を引いて計算します。必要経費には、減価償却費が入り、借入金の元本は入りません。このため、帳簿上の所得と手残りがずれます。

建物の減価償却費を求めるため、例では、建物の価格を900万円、鉄筋コンクリート造、築20年の中古で取得したと仮定します。国税庁の簡便法（[No.5404](https://www.nta.go.jp/taxes/shiraberu/taxanswer/hojin/5404.htm)）では、耐用年数が法定耐用年数47年から経過年数20年を引いた27年に、経過年数の20%の4年を足した31年になります（法定耐用年数は国税庁の[耐用年数表](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/pdf/2100_01.pdf)の住宅用）。償却率は1÷31を小数第4位で切り上げた0.033で、900万円 × 0.033 = 297,000円が1年分です。計算の詳しい手順は[不動産の減価償却の計算方法](/guide/genka-shokyaku-fudousan/)に、自分の物件で試算するならサイト内の[減価償却の計算ツール](/genka-shokyaku/)があります。

空室1か月のケース（手残り82,096円）で並べます。

| 項目（円） | 帳簿上の所得 | 手元のお金 |
|---|---|---|
| 実際の家賃収入 | 880,000 | 880,000 |
| 管理費・手数料・税・保険 | −222,000 | −222,000 |
| 借入金の利子 | −177,267 | −177,267 |
| 借入金の元本 | 経費にならない | −398,637 |
| 減価償却費 | −297,000 | お金は出ない |
| 結果 | 183,733 | 82,096 |

2つの差は、183,733 − 82,096 = 101,637円です。これは、元本の返済 398,637円から、減価償却費 297,000円を引いた金額に一致します。帳簿が黒字でも手元のお金が少ないのは、元本の返済が大きいからで、帳簿が赤字なのにお金が残るのは、減価償却費が大きいからです。

実際の税額は、この所得に各種の控除を反映して決まります。経費に入るものは[不動産所得の経費になるもの一覧](/guide/fudousan-shotoku-keihi/)で確認できます。税額の判断は、国税庁の案内か税理士に相談してください。

## 実際の収支を毎年確かめる

計画の数字は、実際の数字と必ずずれます。年に1回、実際の家賃収入と出費を集計して、計画と比べると、空室や修繕の見込みを直せます。このとき、物件ごとに記録しておくことが前提になります。利回りの計算と見方は[表面利回りと実質利回りの計算方法](/guide/rimawari-keisan/)で説明しています。

ここからは自社アプリの紹介です。motytools（このサイトの運営者）が作っているiPhoneアプリ[大家ノート](/ooya-note/)は、毎月の家賃の入金と、収支タブでの支出を物件ごとに記録できます。Premiumでは、1年分の家賃収入、経費、手元に残ったお金（キャッシュフロー）を物件別にまとめた年間レポートが見られ、PDFとCSVで書き出せます。無料で使えるのは1物件・3室までで、年間レポートはPremium（月額980円・年額9,800円）です。

レポートの数字は、入金があった日で数える参考の集計です。ローン返済の元本は経費から分けて扱われますが、申告上の所得そのものではありません。申告上の所得は、会計ソフトか税理士で確かめてください。
