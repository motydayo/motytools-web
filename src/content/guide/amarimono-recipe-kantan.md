冷蔵庫の余り物を見て「何も作れない」と感じるときは、食材の組み合わせから料理を引ける表があると決めやすくなります。この記事では、余りがちな食材の組み合わせ別に、作れる料理を早見表にしました。後半では、パターンごとに2人分の分量と手順、味付けの基本の比率を載せています。

料理名から探すレシピ記事は多くありますが、ここでは**手元の食材から引ける**ことを優先しました。

## 余り物の組み合わせ早見表

| 手元にあるもの | 作れる料理 | 味の方向 |
|---|---|---|
| 豚こま・キャベツ | 味噌炒め | 和（味噌、みりん、酒） |
| 鶏もも・玉ねぎ | 照り焼き風炒め | 和（しょうゆ、みりん、酒） |
| ウインナー・キャベツ・じゃがいも | コンソメ炒め | 洋（コンソメ、こしょう） |
| 卵・キャベツ | ふんわり炒め | 中（鶏がらスープの素、ごま油） |
| 卵・にんじん・ツナ缶 | にんじんしりしり風 | 和（しょうゆ） |
| 卵・青菜・もやし | 中華風卵スープ | 中（鶏がらスープの素、しょうゆ） |
| 野菜数種類（根菜・葉物） | 具だくさん味噌汁・スープ | 和または洋 |
| 玉ねぎ・じゃがいも・にんじん | カレー粉炒め | カレー（カレー粉、塩） |
| 冷やご飯・卵・ねぎ | 卵チャーハン | 中（鶏がらスープの素） |
| うどん・キャベツ・肉少し | 焼きうどん | 和（しょうゆ、かつお節） |

表に無い組み合わせは、冷蔵庫の食材をタップで選ぶと作れる料理を探せるアプリもあります。ここからは自社アプリの紹介です。motytools（このサイトの運営者）が作っているiPhoneアプリ[あるものレシピ](/arumono-recipe/)は、選んだ食材でそろう料理を、収録の477品から並べます。

## 肉が少しと野菜があるとき

肉は100〜150gあれば、主菜として成立します。**肉は中心まで火を通します。** 厚生労働省は、加熱の目安を[中心部の温度が75℃で1分間以上](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/shokuhin/syokuchu/01_00006.html)としています（2026年10月12日に確認）。切って中の色を確かめてください。

### 豚こまとキャベツの味噌炒め

材料（2人分）: 豚こま切れ肉150g、キャベツ250g、味噌大さじ1と1/2、みりん大さじ1、酒大さじ1、サラダ油小さじ2

1. 味噌、みりん、酒を小さな器で混ぜておく
2. 熱したフライパンに油をひき、豚肉を色が変わるまで炒める
3. ちぎったキャベツを加え、しんなりするまで2分ほど炒める
4. 合わせた調味料を回し入れ、全体にからめて火を止める

### 鶏もも肉と玉ねぎの照り焼き風炒め

材料（2人分）: 鶏もも肉250g、玉ねぎ1/2個、しょうゆ・みりん・酒各大さじ1と1/2、サラダ油小さじ2

1. 鶏肉を一口大に切り、玉ねぎは薄切りにする
2. フライパンに油をひき、鶏肉の皮目を下にして中火で焼く
3. 裏返して玉ねぎを加え、ふたをして弱火で5分ほど蒸し焼きにする
4. しょうゆ、みりん、酒を加え、汁気が半分になるまで煮からめる

### ウインナーとじゃがいものコンソメ炒め

材料（2人分）: ウインナー4本、じゃがいも2個、キャベツ100g、コンソメ（顆粒）小さじ1、こしょう少々、サラダ油大さじ1

1. じゃがいもは薄切りにして耐熱容器に入れ、ふんわりラップをして電子レンジ（600W）で3分加熱する
2. ウインナーは斜め切り、キャベツはちぎる
3. フライパンに油を熱し、ウインナーとキャベツを炒め、じゃがいもを加える
4. コンソメとこしょうをふって全体を混ぜる

## 卵と野菜があるとき

卵は、肉が無い日の主役になります。1人あたり1〜2個が目安です。

### キャベツと卵のふんわり炒め

材料（2人分）: 卵3個、キャベツ250g、鶏がらスープの素小さじ1/2、塩ひとつまみ、ごま油大さじ1

1. 卵を溶き、塩を混ぜる。キャベツはちぎる
2. ごま油半量で卵を半熟に炒めて取り出す
3. 残りのごま油でキャベツを2分炒め、鶏がらスープの素で調味する
4. 卵を戻して軽く混ぜる

### にんじんしりしり風

材料（2人分）: にんじん1本（150g）、ツナ缶1缶、卵2個、しょうゆ小さじ2、塩少々、サラダ油小さじ1

1. にんじんをせん切りにする。ツナは汁気を軽く切る
2. 油で、にんじんをしんなりするまで炒める
3. ツナとしょうゆを加えて混ぜ、溶き卵を回し入れる
4. 卵が固まったら、塩で味を整える

### 中華風卵スープ

材料（2人分）: 卵1個、もやし50g、小松菜1株、水400ml、鶏がらスープの素小さじ1と1/2、しょうゆ小さじ1/2、ごま油少々

1. 水を沸かし、鶏がらスープの素と刻んだ小松菜、もやしを入れて2分煮る
2. しょうゆで味を整え、溶き卵を細く回し入れる
3. 卵が浮いたら火を止め、ごま油をたらす

## 野菜だけのとき

肉も卵も無いときは、野菜の数を2〜3種類に絞って、味付けの方向をはっきりさせます。

- **カレー粉炒め**: 玉ねぎ1/2個、じゃがいも1個、にんじん1/2本（合計約300g）を小さく切り、油大さじ1で炒めます。竹串が通ったら、カレー粉小さじ1と塩小さじ1/4をからめます。じゃがいもは先に電子レンジで加熱しておくと早く仕上がります
- **具だくさん味噌汁・スープ**: 水400mlに野菜200〜250g。火の通りにくい根菜から入れます。野菜ごとの切り方と時間の目安は、[余り野菜を使い切るレシピ](/guide/amari-yasai-recipe/)の表にまとめました

## ご飯や麺が余っているとき

- **卵チャーハン**: 冷やご飯2膳分（約300g）、卵2個、ねぎ少々、鶏がらスープの素小さじ1、塩少々。熱したフライパンに油大さじ1をひき、溶き卵とご飯を一緒に入れて、ほぐしながら炒めます
- **焼きうどん**: ゆでうどん2玉、肉少し（50g）、キャベツ100g、しょうゆ大さじ1、かつお節少々。具を炒めてからうどんを加え、しょうゆで味を付けます

ご飯の保存の注意点や、丼や雑炊など別の展開は[余り物とご飯で作るレシピ](/guide/amarimono-gohan-recipe/)で詳しく説明しています。

## 味付けの基本の分量

迷ったら、次の比率から始めます。これは家庭料理の一般的な目安で、好みやメーカーで変わります。

| 料理 | 目安 |
|---|---|
| 照り焼き・炒め煮（2人分） | しょうゆ:みりん:酒＝1:1:1（各大さじ1〜1と1/2） |
| 味噌炒め（2人分） | 味噌大さじ1と1/2、みりん大さじ1、酒大さじ1 |
| 中華炒め（具300g） | 鶏がらスープの素小さじ1/2、しょうゆ小さじ1、ごま油少々 |
| 洋風炒め（具300g） | コンソメ小さじ1/2〜1、こしょう少々 |
| 味噌汁（水400ml） | 味噌大さじ1と1/2〜2 |
| スープ（水400ml） | コンソメ小さじ2 |

自治体も、食品ロスを減らす使い切りレシピを公開しています。大阪府は、余り野菜や野菜の皮、切り端を使うレシピを[食品ロス削減レシピのページ](https://www.pref.osaka.lg.jp/ryutai/foodloss/reshipi.html)にまとめています。
