あるもので料理ができないときは、腕より先に**決める順番**を見直すと進みます。レシピから入ると、「材料が足りない」で止まってしまうからです。この記事では、料理を「型」「主役」「味」の3手で決める方法と、足りない食材を役割で置き換える方法を、入れる量の目安つきで説明します。

## あるもので料理ができない理由

レシピは、材料がそろっている前提で書かれています。手元の食材に合わせて組み立てる作業は、レシピ通りに作る作業とは別の技術です。つまずく理由は次の3つに分けられます。

- **材料の指定に引っ張られる**: 「豚こまが無いから作れない」と、レシピの材料表で判断してしまう
- **決める順番が分からない**: 野菜も肉も調味料も同時に考えて、頭が止まる
- **味付けの比率を知らない**: 食材は決まっても、調味料の量に自信が持てず、結局レシピを探す

2つ目と3つ目は、決める順番と比率を先に覚えれば解消します。次の表が、この記事全体の地図です。

| 順番 | 決めること | 迷ったら |
|---|---|---|
| 1手目 | 型（炒める・煮る・卵でとじる・ご飯に混ぜる） | 今日の余力で決める。疲れていれば炒め物かスープ |
| 2手目 | 主役（先に使い切りたい食材） | 傷みやすい物、量が多い物、たんぱく質を先に |
| 3手目 | 味（和・洋・中のどれか1つ） | 家にある調味料が多い方向を選ぶ |

## コツ1　主役を1つ決める

主役とは、「これを今日中に使い切りたい」と思う食材です。主役が決まると、ほかの食材は脇役として自動的に絞れます。

主役を選ぶ基準は、次の順です。

1. 傷むのが早い物（葉物、きのこ、もやし、開封した豆腐、肉や魚）
2. 量が多くて残りそうな物（半端に切った大根、キャベツ4分の1など）
3. たんぱく質（肉、魚、卵、豆腐）。主役にすると食事として成立しやすい

主役にした食材のほかに、脇役は2〜3種類までにします。冷蔵庫の物を全部入れようとすると味がまとまらず、洗い物も増えます。残りは翌日の主役にします。

## コツ2　味の方向を先に決める

食材よりも先に、味の方向を和・洋・中のどれか1つに決めます。方向が決まると、調味料の組み合わせが決まり、食材の相性で悩まなくなります。

### 和・洋・中の調味料セット

| 方向 | 調味料セット | 基本の比率・量の目安 |
|---|---|---|
| 和 | しょうゆ、みりん、酒、だしの素 | 照り焼き・炒め煮は「しょうゆ:みりん:酒＝1:1:1」。味噌汁は水400mlに味噌大さじ1と1/2〜2 |
| 洋 | コンソメ、塩、こしょう、バター、ケチャップ | スープは水400mlにコンソメ小さじ2。炒め物はバターと塩こしょうだけでも成立する |
| 中 | 鶏がらスープの素、しょうゆ、ごま油、酢 | 炒め物は具300gに鶏がらスープの素小さじ1/2、しょうゆ小さじ1、最後にごま油少々 |

これは家庭料理の一般的な目安です。濃さは好みと使う調味料の銘柄で変わるので、最初は少なめに入れて味を見ます。足りなければ足す方が、入れすぎを直すより簡単です。

## コツ3　何でも受け止める料理の型を持つ

「型」とは、具が変わっても同じ手順で作れる料理のことです。次の4つを覚えると、冷蔵庫の中身が毎回違っても対応できます。

### 炒め物

肉や卵を先に炒めて取り出し、野菜を炒めて戻す、が基本の流れです。

- 2人分の目安: 具の合計300g前後（肉100g＋野菜200g）
- 入れる野菜: 火の通りにくい物（にんじん、玉ねぎ）を先に、キャベツやもやしを後に
- 味付け: しょうゆ大さじ1弱か、塩小さじ1/3とこしょう。最後に火を止めて混ぜる

### スープ・味噌汁

余り野菜の消化に最も向く型です。切った具を水から煮て、最後に味を付けます。

- 2人分の目安: 水400mlに具200〜250g
- 具の量が多すぎると味が薄まるので、足りなければ味噌を足す
- 肉や卵を入れるとおかずを兼ねられる

### 卵とじ

具を少量の煮汁で煮て、溶き卵を回し入れる型です。

- 2人分の目安: 卵3個、具150g（玉ねぎ、きのこ、青菜など）、水150ml、しょうゆ大さじ1と1/2、みりん大さじ1
- 具を煮汁で2〜3分煮てから溶き卵を回し入れ、半熟で火を止める
- ご飯にのせれば丼、そのままならおかずになる

### 混ぜご飯

具を炒めて味を付け、炊いたご飯に混ぜるだけの型です。炊き込みよりも短時間で、少量の余り物に向きます。

- 2人分の目安: ご飯茶碗2杯（約300g）に、炒めた具100〜120g
- 味付け: しょうゆ大さじ1とごま油少々（和）、バターと塩（洋）。しょうゆは具を炒めるときに入れる

## コツ4　足りない食材は「役割」で置き換える

「レシピの材料が無い」ときは、その食材が料理の中でしている役割を見ます。同じ役割を果たす物があれば置き換えられます。

| 役割 | 置き換えの例 |
|---|---|
| うま味 | かつお節、ツナ缶、ベーコン、ウインナー、鶏がらスープの素、コンソメ |
| とろみ | 片栗粉（大さじ1を水大さじ2で溶く）、溶き卵、すりおろしたじゃがいも |
| 食感 | もやし（シャキシャキ）、れんこん、ごぼう、きのこ（コリコリ） |
| 酸味 | 酢、レモン果汁、ポン酢 |
| 甘み | 砂糖、みりん、玉ねぎを炒めて出る甘み |
| コク | バター、マヨネーズ、ごま油、粉チーズ |
| 彩り | 小ねぎ、大葉、青のり、ミニトマト、パプリカ |

たとえば「豚バラが無いが、ベーコンならある」なら、うま味と脂の役割は同じなので、塩を控えめにして置き換えられます。「ピーマンが無い」なら、役割は彩りと苦みなので、小松菜やししとうが代わりになります。

### 常備しておくと1品になる食材

何もないと感じる日のために、次の物を切らさないでおくと助かります。

- 卵（炒める、とじる、スープに入れる、どれにも使える）
- ツナ缶、さば缶（うま味とたんぱく質を一度に補える）
- 乾麺（パスタ、うどん、そうめん）、ご飯のストック
- 乾物（わかめ、切り干し大根、高野豆腐、かつお節）
- 冷凍の野菜（ミックスベジタブル、ほうれん草など）、缶詰のトマト

## コツ5　迷ったら作れる料理を並べてもらう

型、主役、味の順で決める方法は、慣れれば数十秒で済みます。それでも、疲れた日は決めること自体が負担です。その日は、判断を道具に任せる手もあります。

ここからは自社アプリの紹介です。motytools（このサイトの運営者）が作っているiPhoneアプリ[あるものレシピ](/arumono-recipe/)は、持っている食材をタップで選ぶと、いま作れる料理が一覧で並びます。

[[app]]

仕組みは単純です。食材を選ぶと、収録している477品の家庭料理のうち、選んだ食材でそろう料理が「今すぐ作れる」に出ます。材料が1つだけ足りない料理は「あと1つ」に出て、足りない食材を押すと買い物メモに入ります。しょうゆ、みりん、油などの調味料21品は、最初から「ある」扱いです。

一方で、このアプリは、献立を組み立てる機能や、食材の使い方を教える機能ではありません。収録の477品に無い料理は出ません。型や役割で置き換える考え方は、この記事の方法で身につけ、考えたくない日だけアプリに任せる、という使い分けが現実的です。

## 型を覚える順番

最初から4つ全部を覚える必要はありません。次の順番で1つずつ増やすと、続けやすくなります。

1. 味噌汁・スープ（失敗しにくく、余り野菜の消化に強い）
2. 炒め物（肉・卵・野菜の組み合わせを自由にできる）
3. 卵とじ（卵があればどんな具でも成立する）
4. 混ぜご飯（余ったご飯と少量の具の消化に向く）
