iPhoneの音声入力は、文字を入力できる場所なら、キーボードのマイクのボタンから使えます。この記事では、Appleの公式ガイドで確認した設定の手順、句読点と改行の入れ方、認識の精度を上げるコツ、そして話したメモをそのまま自分宛てに送る方法を説明します（2026年10月12日に、iPhoneユーザガイドで確認）。

## 音声入力の基本

### 使えるようにする

「設定」アプリを開き、「一般」、「キーボード」の順にタップして、「音声入力を有効にする」をオンにします。

### 話して入力する

1. 文字を入れたい場所（メモの本文など）をタップして、入力する位置にカーソルを置く
2. キーボードに出るマイクのボタンをタップする
3. 話す

音声入力を止めるには、次のどれかを行います。

- マイクのボタンをもう一度タップする
- 「音声入力を停止」と話す
- 声を出さずに30秒待つ（自動で止まります）

音声入力中もキーボードは開いたままなので、聞き取りが違った部分は、その場でキーボードで直せます。

### オフラインと通信量

Appleのユーザガイドによると、多くの言語の音声入力はiPhone上で処理され、インターネット接続は必要ありません。ただし、一部の言語や国・地域では使えません。また、検索欄に音声入力すると、検索を処理するために文字が検索エンジンに送られることがあります。音声入力でモバイルデータ通信の料金がかかる場合がある、とも書かれています。

## 句読点・改行の入れ方

Appleのユーザガイドでは、句読点などの記号は、その名前を話して入力すると案内されています。日本語版のコマンドの一覧には、次のものが載っています。

| 話す言葉 | 入る記号・動作 |
|---|---|
| ピリオド、点、ドット、フルストップ | . |
| カンマ | , |
| 感嘆符 | ! |
| 疑問符 | ? |
| 開き丸かっこ・閉じ丸かっこ | ( ) |
| 次の行 | 新しい行を始める |
| 次の段落 | 新しい段落を始める |

ガイドの別の箇所には、「改行」や「新しい段落」と話すと改行できる、とも書かれています。

自動の句読点については、ガイドに次のように書かれています。対応している言語では、音声入力中にカンマ、ピリオド、疑問符が自動で入ります。オフにするには、「設定」の「一般」、「キーボード」で、「自動句読点」をオフにします。

ここで大事な注意があります。日本語で、どの記号が自動で入るのか、「まる」「てん」のような日本語の言い方が使えるかは、ガイドでは確認できません。この記事の筆者は、執筆日に実機で試していません。自分のiPhoneで、短い文章を話して、結果を確かめてください。

## 精度を上げるコツ

認識の精度は、環境と話し方で変わります。次の工夫が役に立ちます。ガイドに書かれた仕様ではなく、筆者が実用上おすすめする内容です。

- **静かな場所で話す。** 周りの話し声や風の音が入ると、聞き違いが増えます
- **短く区切って話す。** 長く話し続けるより、1文ずつ区切るほうが直しやすくなります
- **iPhoneを口から離しすぎない。** 話しながら歩くときは、マイクを覆わない持ち方にします
- **固有名詞は、あとで直す前提にする。** 人名や商品名は、後で書き換えるつもりで進めます
- **話し終えたら、送る前に1度だけ読み返す。** 数字や日付の聞き違いに気づけます

### 人前で使うときの注意

音声入力は、周りにメモの内容が聞こえます。仕事の内容や個人の情報を、人のいる場所で話すのは避けてください。電車の中などでは、声を出さずに、短いキーワードだけを打つ使い分けも現実的です。

## ボイスメモとの違い

iPhoneの録音機能（ボイスメモ）は、声そのものを残します。音声入力は、話した内容を文字にします。

| | 録音 | 音声入力 |
|---|---|---|
| 残るもの | 声（音声ファイル） | 文字 |
| あとで探す | 聞き直して探す | 文字で検索できる |
| 人に送る | 音声ファイルを送る | 文章としてそのまま送れる |
| 向いている場面 | 会議、講義、声の雰囲気も残したいとき | 思いつきのメモ、用件のメモ |

声を残す必要がなければ、文字にしておくほうが、見返すときに探しやすくなります。

## 話したメモをそのまま送る

文字になったメモを、そのまま自分に送れれば、移動中や手がふさがっているときのメモが片づきます。ここからは自社アプリの紹介です。motytools（このサイトの運営者）が作っているiPhoneアプリ「[メモびゅん](/memomail/)」は、音声入力に対応した、自分宛てメール用のアプリです。

使い方の流れは次のとおりです。

1. アプリを開く。音声メモをオンにしていると、起動と同時に聞き取りが始まる（設定の「音声メモ」にある「起動時に音声メモを開く」で切り替えられる）
2. 初回は、マイクと音声認識の許可を求められるので、許可する
3. 話す。話した内容が文字になって、入力欄に出る
4. 画面の聞き取り中の表示をタップすると、聞き取りが止まる
5. 文字を確認して、「送信」を押す。登録した自分のメールアドレスに届く

注意点が2つあります。聞き取り中は、認識された文字で入力欄が更新されます。直したい部分は、聞き取りを止めてから直してください。また、聞き取りは日本語に固定されています。

無料プランは1日3通まで、Proは月額500円（年額4,800円）で1日30通までです。テキスト専用で、録音した声そのものは送れません。Android版もありません。

通信できない場所では、メモは「未送信」として端末に保存されます。自分宛てにメールを送る方法の全体は[iPhoneで自分にメールを送る方法](/guide/jibun-ni-mail-iphone/)にまとめています。ほかのメモアプリとの違いは[アイデアメモアプリおすすめ](/guide/idea-memo-app/)に、メモを見返す仕組みは[メモしたのに忘れる人へ](/guide/memo-wasure-boushi/)にあります。
