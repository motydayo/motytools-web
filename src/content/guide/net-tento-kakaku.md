同じ商品でも、ネットと店頭で価格が違うのは珍しくありません。どちらが安いかは商品と時期で変わるので、決まった答えはありません。確かなのは、本体価格だけで決めると損をしやすいことです。この記事では、価格が違う理由、総額で比べる方法、店頭でその場でネットの価格を確かめて相談する手順を説明します。

## 価格が違う理由

### 店やサイトごとに価格を決めている

ヨドバシ.comのヘルプには、地域の市場動向などによって、店舗とネットの販売価格が異なる場合があるという趣旨の案内があります（2026年10月12日に確認）。店舗ごとに独自のセールや特価を行うこともあるとされています。

家電量販店の価格の決め方については、業界メディアのBCNが2020年11月に書いた解説があります。それによると、ネットと店頭の価格を同じにしている企業もあれば、違う企業も多く、店頭のほうが安いこともあるとされています。2020年の記事なので、今の各社の方針とは違う可能性があります。

### 店頭の価格もネットに合わせて動く

ビックカメラは、価格変動の激しいネット通販に店頭が対応するため、本部から一括で値札の価格を変えられる電子ペーパーの値札を、全41店舗に導入する予定だと2019年に報じられました（[ギズモード・ジャパンの記事](https://www.gizmodo.jp/article/biccamera-new-price-tag/)）。こうした仕組みが広がると、店頭の価格も日々変わります。

BCNの記事は、電子棚札の価格は会員セール価格や店舗ごとの特価を含まない場合があるので、店頭で実際の価格を確かめる意味があると指摘しています。つまり、先週のネットの価格を覚えていても、今日の店頭と比べる材料にはなりません。**比べるなら、同じ日に、同じ条件で**が原則です。

## 比べるときは「総額」で

比べるのは、画面に大きく出ている本体価格ではなく、**最終的に自分が払う額から戻るポイントを引いた額**です。確かめる項目を表にしました。

| 項目 | 店頭 | ネット | 確認する場所 |
|---|---|---|---|
| 本体価格（税込） | | | 値札、商品ページ |
| ポイント（付与される額） | | | 値札、商品ページ、注文確認画面 |
| 送料 | | | 商品ページ、カート |
| 設置・搬入費 | | | 店員、商品ページの注意書き |
| 古い家電の引き取り | | | 店員、商品ページ |
| 延長保証の料金と年数 | | | 店員、商品ページ |
| 納期・受け取り日 | | | 店員、商品ページ |

空欄を埋めて、「本体価格＋送料＋設置・搬入費＋引き取り費＋延長保証−ポイント」を計算します。

### ポイント

ポイントは、いつ、どんな種類で戻るかが人によって違います。たとえば楽天市場のSPUという仕組みは、倍率が会員の条件で変わり、表示される最大は18.5倍です。付与されるのは期間限定ポイントが多く、買い物の翌月15日ごろに付与され、使える期限があります（2026年10月12日に[楽天の公式ページ](https://event.rakuten.co.jp/campaign/point-up/everyday/point/)で確認）。Yahoo!ショッピングは、商品一覧に獲得できるPayPayポイントが表示され、通常と期間限定の2種類があります（[Yahoo! JAPANヘルプセンター](https://support.yahoo-net.jp/PccShopping/s/article/H000005932)、同日確認）。

店頭のポイントも店ごとに違います。比べるときは、**使える見込みの高いポイントだけを1ポイント1円で数える**のが現実的です。期限が切れそうなポイントや、使い道のないポイントは、値引きと同じ価値には見なせません。

### 送料・設置費・リサイクル料

大型の家電は、ネットで買うと設置や搬入が別料金になることがあります。店頭で買って持ち帰るなら、かからない費用です。

洗濯機、冷蔵庫、エアコン、テレビを買い替えるときは、古い物を処分する費用も忘れずに確かめます。環境省の[家電リサイクル法の概要](https://www.env.go.jp/recycle/kaden/gaiyo.html)では、この4品目を捨てるとき、消費者が収集運搬料金とリサイクル料金を払う決まりです。小売業者には引き取りの義務が定められており、金額は品目やメーカー、店で違います。買う前に、引き取り料金を店とネットの両方で確かめてください。

### 延長保証

延長保証は、年数、対象の故障、料金、窓口が店ごと、サイトごとに違います。安い本体価格に延長保証を付けたら、店頭の保証込みの価格より高くなる、ということもあります。保証を付けるつもりなら、**保証込みの価格同士で**比べます。

### 計算例（架空の数字）

洗濯機を買う場合の例です。金額はすべて説明用の仮の数字です。

- 店頭：本体98,000円、ポイント10％（9,800円分）、標準設置込み。実質は98,000−9,800＝**88,200円**
- ネットA：本体92,000円、ポイント1％（920円分）、設置・搬入3,300円が別。実質は92,000＋3,300−920＝**94,380円**
- ネットB：本体82,000円、ポイント8％（6,560円分）、設置・搬入3,300円が別。実質は82,000＋3,300−6,560＝**78,740円**

本体価格だけを見るとネットAのほうが安く見えますが、総額では店頭より6,180円高くなります。ネットBでは、店頭より9,460円安くなります。同じ商品でも、条件で結果が変わります。

## 店頭でネット価格を確かめる

店で気になる商品を見つけたら、買う前に1分でネットの価格を確かめます。

1. 商品の型番を確認する。家電は、本体や箱に書かれた型番（アルファベットと数字の並び）で見分ける。色や容量だけが違う別モデルもあるので、末尾まで一文字ずつ合わせる
2. バーコードを読み取るアプリで調べる。当サイトを運営するmotytoolsが作っている自社のiPhoneアプリ「[ピッと最安](/price-scan/)」の場合、アプリを開いてバーコードを枠に合わせると、楽天市場とYahoo!ショッピングの価格が出ます
3. 結果画面の価格をタップして商品ページを開き、送料、ポイント、納期、販売しているのがどの店かを見る
4. 画面のスクリーンショットを撮っておく（交渉に使う）

ピッと最安は、型番やJANコードで管理される家電、化粧品、本、飲料などが得意です。苦手なのはパン、惣菜、生鮮食品で、これらは通販に出回らないため価格が出ません。Amazonと価格.comは価格を表示せず、検索結果を開くボタンで移動します。ポイントを引いた実質価格の計算もしません。家電を買うときは、結果画面の本体価格を、先ほどの総額の表に当てはめてください。

## 価格交渉のマナー

ネットの価格を示して値引きを相談するときは、次の点を守ると話が進みやすくなります。

- **聞き方は相談にする**。「この価格にしてください」ではなく、「ネットでこの価格を見たのですが、合わせていただくことはできますか」と聞く
- **条件を同じにして見せる**。同じ型番、新品、送料やポイントを含めた総額の画面を用意する。ほかの出品者が売っているマーケットプレイスの商品や、中古、並行輸入品は、同じ条件の比較になりません
- **応じてもらえなくても引き下がる**。値引きは店舗の判断で、必ず応じるとは限りません。BCNの記事は、量販店は競合のネット価格まで対抗することが多いと書いていますが、これは2020年の一般論で、店ごと、商品ごとに事情が違います
- **値引き以外の相談もする**。本体の値引きが難しくても、設置費、延長保証、ポイントの付け方で調整できる場合があります
- **混んでいる時間を避ける**。レジやカウンターが空いているときのほうが、店員も落ち着いて対応できます

店頭のほうが高くても、すぐ使いたい、設置を任せたい、故障のときに店に持ち込みたいなら、店頭を選ぶ価値があります。逆に、価格の差が総額で大きく、置き場所と設置にも問題がなければ、ネットを選ぶのも自然な判断です。楽天とYahoo!のどちらで買うかは、[楽天とYahoo!ショッピングはどっちが安いか](/guide/rakuten-yahoo-hikaku/)で比べ方を説明しています。
