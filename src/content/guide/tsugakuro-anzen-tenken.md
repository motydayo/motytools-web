通学路の安全は、学校や自治体の点検だけでなく、保護者が自分の目で歩いて確かめることで、見えてくることがあります。この記事では、歩く前の下調べ、歩いて確かめる15項目のチェックリスト、子どもと一緒に歩くときの声かけ、気づいた危険を伝える方法を説明します。印刷して、メモ欄に書き込めます。

## 歩く前に記録で下調べする

いきなり歩く前に、通学路の周りで、過去にどんな記録があるかを調べておくと、歩くときに重点を置く場所が決まります。

- **交通事故**: 警察庁のオープンデータや、警察・新聞社の事故マップで、事故が起きた場所と時間帯を調べます。見方は[交通事故が多い場所の調べ方](/guide/koutsujiko-tashuu/)で説明しています
- **不審者情報**: 県警察のメールや地図で、声かけ・つきまとい等の発生場所を調べます。見方は[不審者情報をマップで見る方法](/guide/fushinsha-joho-map/)にあります
- **学校からのお知らせ**: 学校や自治体が出す、通学路の危険箇所の資料を確かめます

ここからは自社アプリの紹介です。motytools（このサイトの運営者）が作っているiPhoneアプリ「[まちの安全マップ](/machi-anzen-map/)」は、住所や駅名を入れると、その周り半径500mと1kmの交通事故と不審者情報（27都道府県）の件数を、出典つきで表示します。

[[app]]

自宅と学校の2か所を「この場所を保存」しておくと、あとで開き直す手間が省けます。保存した場所は端末の中だけに残り、会員登録はいりません。

できないことも書いておきます。道に沿ったルート全体の件数を出す機能はなく、選んだ地点の周りを円で数えます。通学路が長いときは、途中の地点も1か所ずつ調べてください。件数は、危険の度合いではありません。0件は安全の意味ではなく、不審者情報は27都道府県以外は「対象外」と表示されます。アプリは無料（広告あり）で、広告を消すのは買い切りです。

## 交通の危険のチェック

交通事故にあわないためのチェックです。登校の時間帯と、下校の時間帯の両方で、同じ道を確かめます。

|---|---|---|---|
| 1 | 歩道や路側帯があるか。幅は子どもが並んで歩いても余裕があるか | □ | |
| 2 | 横断する場所に、信号や横断歩道があるか。待つ場所は車道から離れているか | □ | |
| 3 | 交差点や曲がり角で、車が来るのが見えるか（駐車車両、植え込み、看板で隠れないか） | □ | |
| 4 | 朝と夕の車の通りはどうか。抜け道になって、速度を出す車や大型車が通らないか | □ | |
| 5 | 歩道に自転車や置き物が出ていないか。工事で迂回する場所や、踏切はないか | □ | |

## 逃げ込める場所のチェック

何かあったときに、子どもが駆け込める場所を確かめます。警視庁は、親子で通学路や、自宅と習い事の間の道を一緒に歩いて、駆け込める場所を確認すること、コンビニなどの店は親子で実際に入ってみることをすすめています（[警視庁](https://www.keishicho.metro.tokyo.lg.jp/kurashi/higai/kodomo/kodomo110.html)）。

| 番号 | 確認すること | □ | メモ |
|---|---|---|---|
| 11 | 「子ども110番の家」の位置と、そのマークが見えるか。地域で定着している標識か | □ | |
| 12 | コンビニ、商店、交番・駐在所、学校、公共施設が、道のどのあたりにあるか | □ | |
| 13 | 「ここで何かあったら、どこに行く」と、道の途中ごとに子どもが答えられるか | □ | |

「子ども110番の家」は、子どもが危険に遭ったり、困ったりしたときに立ち寄れる、民間協力の拠点です。自治体や教育委員会が中心となり、地域のボランティアが運営しています。協力してくれている家や店は、時期によって変わることがあるので、現在の場所を学校や自治体で確かめてください。

| 番号 | 確認すること | □ | メモ |

| 14 | 雨の日に水たまりができる場所や、冬の日没前後に暗くなる場所はどこか | □ | |

15番について、警視庁は、ランドセルの肩ベルトや習い事のバッグなどに防犯ブザーを付け、いつでも使えるよう電池を確認し、ブザーを押す練習をするようにすすめています。

## 子どもと一緒に歩くときの声かけ

点検は、保護者が1人で歩くだけでなく、子どもと一緒に歩くと、子どもの目線で気づけることがあります。次の声かけがおすすめです。

- 「ここは車が見えにくいね。どうしたらいいと思う？」と、危険な理由を、質問の形で一緒に考える
- 「ここで怖いことがあったら、どこに行く？」と、駆け込める場所を、子ども自身に指さしてもらう
- 「こんなときは〇〇ちゃん（くん）だったらどうする？」と、場面を想定して、実際の動きを試してみる（警視庁が紹介しているやり方です）
- 危険な場所を教えるときは、場所を怖がらせるのではなく、「だからこうしよう」という行動とセットで伝える

子どもが声かけやつきまといを保護者に話さず、黙っていることがあります。警視庁は、いつもと様子が違うときはやさしく声をかけることと、些細なことでも警察と学校に連絡することを呼びかけています。

怖がらせずに地域の情報を伝える方法は、[通学路の不審者対策](/guide/kodomo-bouhan-tsugakuro/)で詳しく説明しています。

## 気づいた危険を学校・自治体に伝える

見つけた危険は、個人で抱え込まずに伝えます。

通学路は、法令で、児童が1日におおむね40人以上通行する道路の区間などとされ、小学校では校長が指定します（東京都町田市の資料による）。町田市は、学校やPTAなどの保護者が出した危険箇所の要望書をもとに、警察、道路管理者、教育委員会、学校、保護者が合同で現地を調べ、対策を決める仕組みです。点検後の対策は、年度内を目途に順次実施されます（[町田市](https://www.city.machida.tokyo.jp/kodomo/kyoiku/keikakutou/kibohaiti/gakko-togo-kaichiku/minaminarusechiku/kentoukai_minaminaruse.files/4-04-1.pdf)）。

東京都東久留米市のプログラムでは、保護者が危険箇所を抽出して要望書を作り、学校を通じて教育委員会に出す流れです。そのあと、日程を調整して合同で点検し、対策案を作って実施し、効果を確かめるところまでが決まっています。この仕組みは、平成24年に全国で登下校中の児童が死傷する事故が相次ぎ、文部科学省からの通知を受けて、合同点検を行ったことが出発点とされています（[東久留米市](https://www.city.higashikurume.lg.jp/_res/projects/default_project/_page_/001/004/448/up.pdf)）。

仕組みは自治体ごとに違うので、まず学校に「通学路の危険箇所はどこに伝えればよいか」を聞いてください。伝えるときは、次の内容をメモしておくと、動いてもらいやすくなります。

- 場所（交差点名、目印、地図に印を付けたもの）
- 時間帯と状況（朝の7時台に車が増えるなど）
- 写真（人が写らないようにします）
- 困っていることと、希望する対策（横断歩道の設置、見通しを妨げる物の移動など）

道路の陥没や、信号の故障のように急ぐ危険は、道路を管理する自治体や警察署に直接連絡してください。

引っ越し先の通学路を調べる流れは[引っ越し先の治安の調べ方](/guide/hikkoshi-chian-shirabekata/)にもあります。
