月謝の管理表は、**生徒一覧と月ごとの入金表の2枚のシート**があれば作れます。この記事では、列見出しと数式をそのままコピーして使える形で書きます。未納を赤く目立たせる条件付き書式、月ごとの合計、兄弟割引や休会の扱いまで入れました。数式は、生徒3人のサンプルデータを入れて計算結果を確かめています。

## 月謝管理表に必要な2枚のシート

### 生徒一覧

1人1行の台帳です。入金表は、ここから生徒の名前や月謝額を引いてきます。1行目に次の見出しを入れます。

| 列 | 見出し | 入れるもの |
|---|---|---|
| A | 生徒ID | S001、S002 のように重ならない番号 |
| B | 氏名 | |
| C | ふりがな | |
| D | 保護者名 | 兄弟を見分けるために使う |
| E | 連絡先 | 電話番号など |
| F | コース・曜日 | 月曜16時、のように |
| G | 月謝額 | 割引前の金額 |
| H | 割引額 | なければ0 |
| I | 請求額 | 数式 `=G2-H2` を入れて、下にコピー |
| J | 入会月 | 2026/4/1 のように、月の1日で入れる |
| K | 状態 | 在籍・休会・退会 |
| L | メモ | |

名前だけでなくIDを持たせるのは、同姓同名や名前の変更があっても、入金表との結びつきが崩れないようにするためです。生徒台帳の作り方は[個人教室の生徒管理表の作り方](/guide/seito-kanri-kojin/)で詳しく書いています。

### 月ごとの入金表

1行が1人、1列が1か月の表です。次の配置にします。

| セル | 入れるもの |
|---|---|
| A1 | 支払期日（毎月何日） |
| B1 | 25 など（数字） |
| A3〜D3 | 生徒ID、氏名、請求額、入会月 |
| E3 | `=DATE(2026,4,1)`（年度の最初の月） |
| F3〜P3 | `=EDATE(E3,1)` をE3から右へコピー |
| 4行目〜53行目 | 生徒（50人分） |

E3〜P3には、表示形式を「ユーザー定義」にして `m"月"` と入れると、「4月」「5月」と表示されます。

## 作り方の手順

1. 「生徒一覧」シートを作り、上の見出しと生徒のデータを入れる
2. 「入金表」シートを作り、上の配置で見出しを入れる
3. 入金表のA4に生徒ID（S001など）を手入力する
4. B4に次の数式を入れ、C4とD4は参照する列だけ変えて入れる（C4は$I、D4は$J）

```
=IF(A4="","",INDEX(生徒一覧!$B$2:$B$51,MATCH(A4,生徒一覧!$A$2:$A$51,0)))
```

5. A4〜D4を選び、53行目までコピーする
6. 入金があった月のセルに、**入金額（数字）**を入れる。休会、免除、退会後の月は「休」と入れる

入金額を入れるだけなので、入力は1回で済みます。「入金日」は残らないので、手渡しの日付を記録したい場合は、セルにコメントを付けるか、別の列を足します。

### 未納を色で知らせる

入金表のE4〜P53を選び、条件付き書式で2つのルールを作ります。エクセルは「ホーム」の「条件付き書式」から「新しいルール」、「数式を使用して、書式設定するセルを決定」を選びます。Googleスプレッドシートは「表示形式」の「条件付き書式」で、「カスタム数式」を選びます。**範囲の左上（E4）を基準に数式を書く**のが決まりです。

**赤（支払期日を過ぎても未入金）**

```
=AND($A4<>"",E$3>=$D4,DATE(YEAR(E$3),MONTH(E$3),$B$1)<TODAY(),E4="")
```

**黄色（今月分で、期日前の未入金）**

```
=AND($A4<>"",E$3>=$D4,E$3<=DATE(YEAR(TODAY()),MONTH(TODAY()),1),DATE(YEAR(E$3),MONTH(E$3),$B$1)>=TODAY(),E4="")
```

入会前の月は、`E$3>=$D4` の条件で色が付きません。「休」を入れたセルは空欄ではないので、色が付きません。サンプルで確かめた結果は次のとおりです（今日が2026年10月12日、支払期日が25日の場合）。

| 生徒 | 状況 | 9月分 | 10月分 |
|---|---|---|---|
| S001 | 4〜9月は入金済み（8,000円） | 色なし | 黄色 |
| S002 | 8月は休、9月は未入金 | 赤 | 黄色 |
| S003 | 9月に入会、9月は入金 | 色なし | 黄色 |

### 月の合計を出す

入金表の55行目から下に、月ごとの合計を作ります。E列の数式を、右へコピーします。

| 行 | 見出し | E列の数式 |
|---|---|---|
| 55 | 入金合計 | `=SUM(E4:E53)` |
| 56 | 請求予定 | `=SUMPRODUCT(($A$4:$A$53<>"")*($D$4:$D$53<=E$3)*(E$4:E$53<>"休"),$C$4:$C$53)` |
| 57 | 未入金の件数 | `=IF(E$3>DATE(YEAR(TODAY()),MONTH(TODAY()),1),"",SUMPRODUCT(($A$4:$A$53<>"")*($D$4:$D$53<=E$3)*(E$4:E$53="")))` |

先ほどのサンプルでは、9月分の請求予定は21,000円（S001が8,000円、S002が7,000円、S003が6,000円）、入金合計は14,000円（S001とS003）、未入金は1件（S002）になります。S002の7,000円は、月謝8,000円から兄弟割引1,000円を引いた請求額です。**57行目の「未入金」には、支払期日の前の今月分も含まれる**ことに注意してください。

## よくある例外の扱い

### 兄弟割引

生徒一覧の「割引額」に金額を入れると、請求額が自動で変わり、入金表の請求予定にも反映されます。たとえば2人目から1,000円引きなら、2人目の割引額に1000と入れます。保護者名の列があれば、兄弟を並べて確認できます。

### 月途中の入会・退会

入会月を、入会した月の1日で入れます。初月の月謝を日割りにするか、満額にするかは、先に規約で決めてください。日割りにした月は、通常の請求額と違うので、**入金表の請求予定が実際とずれます**。該当のセルに実際の金額を入れ、コメントで理由を書いておきます。計算のしかたは[月謝の日割り計算のしかた](/guide/gessha-hiwari-keisan/)にまとめました。退会した生徒は、退会後の月に「休」を入れるか、状態を「退会」にして行を残します（過去の入金の記録は、あとで確認が必要になることがあるので消さずに残します）。

### 休会

休会の月は「休」を入れます。休会中も席を確保する教室なら、休会費を請求額として入れても構いません。

### 振替

振替は、月謝の表とは別の「振替」シートに作ります。

| 列 | 見出し | 入れるもの |
|---|---|---|
| A | 生徒ID | |
| B | 欠席日 | |
| C | 期限 | `=B2+60`（60日は教室の決めた日数） |
| D | 使った日 | 振替を受けた日 |
| E | 状態 | `=IF(D2<>"","消化済",IF(TODAY()>C2,"期限切れ","残り"))` |

「残り」の行だけを絞り込むと、今抱えている振替の一覧になります。ルールの決め方は[振替レッスンのルールの決め方](/guide/furikae-lesson-rule/)を参照してください。

## 個人情報の扱い

この表には、生徒と保護者の名前や連絡先が入ります。個人情報保護委員会のQ&Aでは、持っている個人情報の数が少ない小規模な事業者も、個人情報取扱事業者に当たるとされています（[個人情報保護委員会のQ&A](https://www.ppc.go.jp/personalinfo/faq/APPI_QA/)、2026年10月12日確認）。ファイルにパスワードを付ける、共有する範囲を決める、持ち出す端末に入れない、不要な連絡先は持たない、の4点は最低限守りたいところです。

## 表が続かないときは

表の管理が止まる理由は、だいたい次の3つです。

- 月が変わるたびに、列や行を直す作業が出る
- 数式を消してしまい、合計がずれる
- 外出先でスマホから入力しにくい

振替の更新漏れが出る、生徒が10人を超えて表が重い、と感じたら、道具を変える時期です。

ここからは自社アプリの紹介です。motytools（このサイトの運営者）が作っているiPhoneアプリ「[レッスン手帳](/apps/lesson-techo/)」は、この表でやっていることを1台で行います。月謝タブで「◯月分を作成する」を押すと、月謝制の生徒の分が一括で作られ、未納はホームに件数で出ます。入金は、生徒の行の「未納」の表示をタップして、現金・振込・その他を選んで記録します。欠席からの振替権の発行と期限の管理も、同じアプリの中でできます。
